## 目标

- 在此之前，本项目**从未做过真导出** —— 「能导出一个玩家双击就能跑的 exe」一次都没验证过。
- 这是 E8（可发布工程）的第一硬门槛。

## 实现要点

1. 装导出模板（4.7 stable 对应版本），配置 Windows 预设（图标 / 版本信息 / 公司名）。
2. 导出产物要**真的跑一遍**（不是停在「导出成功」）。
3. 导出脚本要能命令行复现（供 T5-10 的 CI 冒烟使用），并注意控制台版引擎 `*_console.exe` 便于抓输出。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 一条命令行可复现导出（写进 `docs/`，不是只写在提交信息里）。
- [ ] **A2** 导出的 exe **实测能启动并进到可操作状态**（给出版本与截图）。
- [ ] **A3** 导出产物不包含 `.godot/` 与调试残留；二进制不入库（保持忽略）。
- [ ] **A4** 导出过程与运行期间控制台无脚本报错。

## 回退

- 若导出模板不可得（版本不匹配），停下来告知用户并请其确认引擎 / 模板，不要擅自换版本。
