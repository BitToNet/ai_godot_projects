## 目标

- 现在无论拿什么武器，玩家都是同一套攻击 / 蓄力 / 剑气。
- 「换武器 = 换打法」是 ⑤「变强」之后**让变强有意思**的关键，也是阶段二第一块。

## 实现要点

1. `WeaponMoveset` 定义：攻击段数 / 每段伤害倍率 / 前摇后摇 / 是否可蓄力 / 剑气与否 / 射程与判定盒。
2. 把 `PlayerFighter` 里现有硬编码的招式数值搬进 moveset；**默认武器必须与今天逐位一致**。
3. moveset 挂在 `ItemCatalog` 的武器条目上 ⇒ 从商店买到的新武器自带新招式。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 本任务的**设计稿先写进本卡**（数据结构 + 每把武器的数值表 + 边界行为），复核通过后才开工。
- [ ] **A2** `moveset_check` 断言：每把武器的段数 / 倍率 / 前摇后摇合法；**默认武器 == 今日硬编码值（逐字段）**。
- [ ] **A3** 脚本化 Boss 战在默认武器下的伤害台账与今天逐位一致；换武器后必须不同。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若数据驱动的招式表让战斗手感变差，保留「默认武器」为手写特例并在本卡记明。
