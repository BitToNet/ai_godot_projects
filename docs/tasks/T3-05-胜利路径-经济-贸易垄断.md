## 目标

- E2 要求 ≥3 条可重复胜利路径；经济是第一条：靠贸易与繁荣度把对手挤死。
- 胜利路径让「一局游戏」有终点，这是商业级与 Demo 的分水岭。

## 实现要点

1. 定义经济胜利的可量化条件（如控制 N 座高繁荣度城镇 / 累计财富阈值）。
2. 条件必须在 HUD / 面板上可见（玩家要知道自己离胜利多远）。
3. 胜利结算界面（与 Boss 战结算同风格）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（胜利条件公式 + 判定时机 + 界面显示字段）并复核。
- [ ] **A2** 断言：脚本化跑到条件即触发胜利；条件未达成不误触发。
- [ ] **A3** 断言：胜利后世界时间 / 输入状态干净（不残留暂停或锁）。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退
