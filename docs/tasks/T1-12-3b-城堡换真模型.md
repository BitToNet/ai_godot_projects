## 目标

- 城堡是三类定居点里最后一个程序化盒子；换完它，**全部 18 个定居点**都是真模型。
- 城堡也是「战略要地」的视觉锚点，风格统一对观感影响最大。

## 实现要点

1. 与 T1-11 同款做法（布局表 + 落位器 + 全有或全无回退）；城堡体量大，注意**包围盒与用地半径**。
2. 程序化路径不动 ⇒ 几何不进指纹。
3. 许可与溯源同 T1-11。
4. 城堡常在山地 / 隘口，落位器要处理**坡度**（村庄是平地，这条是新增难点）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** `asset_check` 扩展断言：城堡布局落位 + 全有或全无回退生效。
- [ ] **A2** 人工核查：`visual_shot.gd --focus=castle` 出图，确认**在坡地上不悬空 / 不埋入**。
- [ ] **A3** 门禁全绿，且生成指纹**一字不变**。
- [ ] **A4** 三个 kind 的定居点都能在真模型路径下正常生成（18/18 无回退到程序化）。

## 回退

- 若坡地落位不稳，允许城堡只用「平地友好」的模型子集，并接受程序化地基作兜底（记明）。
