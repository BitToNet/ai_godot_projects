## 目标

- 管道与文案就位后，玩家要能真的切语言，且**排版不能崩**。
- 中文与拉丁字母的字宽 / 基线差别很大，界面必须验证。

## 实现要点

1. 语言选择在设置里；立即生效并可持久化。
2. 字体回退链（缺字形时不许出现方块 / 豆腐块）。
3. 界面要能容纳**更长的英文**（德语等更长语言要预留）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（字体回退链 + 界面长度校验清单）并复核。
- [ ] **A2** 人工核查：**每个界面**在中 / 英下各出一张截图，确认无截断 / 无重叠 / 无豆腐块。
- [ ] **A3** 断言：切换语言后所有已迁文案变化，且 `ui_total` 仍为 0。
- [ ] **A4** 门禁全绿。

## 回退

- 若某界面装不下英文，优先改布局而不是缩字号（缩字号在商业级里更容易被骂）。
