## 目标

- 外部资产已经有两类（4 个 CC0 GLB + 音频素材），但**没有一条断言**保证「每个外部文件都有许可与出处」。
- 商业级发布时，一个无出处的文件就足以让上架卡住。

## 实现要点

1. 建总清单：文件路径 / 来源 / 许可 / 是否要求署名 / 获取日期。
2. 用**静态断言**保证清单与磁盘实际文件一一对应（多一个或少一个都报红）。
3. 与 T5-07 的游戏内许可界面同源（一份数据两处用）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** `tools/license_check.gd` 断言：`assets/` 与 `audio/` 下每个外部文件都在清单里、许可字段非空、来源可追溯。
- [ ] **A2** 人为加一个无出处的文件 ⇒ 断言**报红**。
- [ ] **A3** 清单与游戏内许可界面显示一致。
- [ ] **A4** 门禁全绿，项数 +1。

## 回退

- 若逐文件静态断言对音频素材过慢，改为「按目录校验 + 汇总清单」两级，并在本卡写明覆盖范围与漏检风险。
