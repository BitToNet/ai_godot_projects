## 目标

- 阶段二引入了大量新数值（招式 / 技能 / 战争 / 会战），必须有一条**回归网**防止平衡被后续改动悄悄打崩。
- §E.9 R6 明确列为风险：已校准的 AI 平衡基线不能被破坏。

## 实现要点

1. 把可量化的平衡指标固化成基线：一场标准战的时间 / 玩家胜率 / 平均伤亡 / 经济收支。
2. 用**固定种子 + 脚本化战斗**跑（不依赖人工操作），结果可比。
3. 指标超容差判失败，容差要写明理由。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（指标清单 + 容差 + 跑法）并复核。
- [ ] **A2** `balance_check` 能在门禁里跑完且稳定（多次运行结果一致）。
- [ ] **A3** 人为把某个数值改坏（临时、不提交）⇒ 断言必须**报红**。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若指标波动大，先只保留最稳的两三项（如标准战时长、玩家胜率），其余记 WARN。
