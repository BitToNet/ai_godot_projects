## 目标

- 陌生玩家第一次启动不该看到黑屏或崩掉：要能自己选一个跑得动的画质档。
- 这是「外部测试轮（T5-06）」能不能顺利的前置。

## 实现要点

1. 首次运行：分辨率与窗口模式选择 + 画质档推荐（基于 GPU / 实测帧率）。
2. 档位建议必须**可覆盖**（玩家能改）且失败时可回退到最低档。
3. 无存档时的引导衔接 T4-05。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（侦测依据 + 推荐逻辑 + 回退行为）并复核。
- [ ] **A2** 断言：删掉配置文件后走首跑分支；有配置时跳过；最低档一定能进游戏。
- [ ] **A3** 人工核查：模拟低端档进游戏不崩。
- [ ] **A4** 门禁全绿；`ui_total` 仍为 0。

## 回退

- 若自动侦测不可靠，先只做「分辨率 + 窗口模式」选择，画质用固定默认。
