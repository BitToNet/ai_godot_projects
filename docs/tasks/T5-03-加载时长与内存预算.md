## 目标

- 4096 m 生成需 **24.3 s**（已实测）；上架版本不能让玩家干等，必须有进度反馈或预算。
- 内存峰值目前**从未测过**。

## 实现要点

1. 测首次启动到可操作的时长（含生成与装配）与内存峰值。
2. 加载要有进度与可取消（或至少不假死）。
3. 定预算：首次启动 ≤ N 秒、内存峰值 ≤ M MB。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（测法 + 预算值 + 超预算时的降级策略）并复核。
- [ ] **A2** 实测：首次启动时长与内存峰值有数字，且落在预算内。
- [ ] **A3** 人工核查：加载期间界面有进度、不白屏假死。
- [ ] **A4** 门禁全绿；生成指纹与统计一字不变。

## 回退

- 若生成时长压不下来，改为「先出可用地图 + 后台补细节」的两段式加载并记明。
