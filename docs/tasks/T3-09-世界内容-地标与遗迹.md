## 目标

- 4096 m 的大地图目前内容密度偏低（定居点相对更聚团，见 `PLAN.md` §25.2 C 的观察项）。
- 地标 / 遗迹是给大地图「可探索性」的最直接手段。

## 实现要点

1. 地标类型（废墟 / 石阵 / 洞窟 / 渡口遗迹）+ 发现奖励（战利品 / 声望 / 情报）。
2. 落位要**避开**定居点与道路（复用既有落位判据）。
3. **必须重基线**（会改世界内容）—— 显式接受并记录 diff。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（地标类型表 + 落位规则 + 奖励）并复核。
- [ ] **A2** 断言：落位不重叠、不在定居点内、可在图上被找到。
- [ ] **A3** 世界内容变了 ⇒ **显式重基线**（指纹 / scale / perf）并在提交里贴 diff。
- [ ] **A4** 门禁全绿。

## 回退

- 若重基线波及过大，先只加**不参与生成**的表现层地标，避免动 RNG。
