## 目标

- 目标函数有了，还需要**后果**：打下来的城真的换旗，丢了真的丢。
- 这让世界会变，也让玩家的胜利路径（T3-07）有载体。

## 实现要点

1. 定居点归属变更（驻军清零 / 换势力 / 繁荣度惩罚）。
2. 战争状态机：开战 / 停战 / 贡金；与 `CampaignDirector` 的目标挂钩。
3. 玩家参与的攻城结算（可以先用遭遇战同款，攻城专用战斗留到阶段三）。
4. 存档要能存「当前归属」（T1-09 的 v2 基础上扩展，必要时 v3）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（归属变更规则 + 战争状态机 + 存档字段）并复核。
- [ ] **A2** `campaign_check` 断言：归属变更后势力色 / 驻军 / 繁荣度都按规则变；停战条件可达。
- [ ] **A3** 存档往返：归属变更后存读档，状态一致（扩 `save_check` 或新增断言）。
- [ ] **A4** 门禁全绿；生成指纹与统计一字不变。

## 回退

- 若攻城战斗成本过高，先做「驻军对抗的自动结算 + 结果播报」，手动攻城留到阶段三。
