## 目标

- 商业级必须有难度选择；也让平衡不必在一个点上死磕。
- 难度必须**只调数值**，不许改规则（否则断言要分叉指数增长）。

## 实现要点

1. 三档（轻松 / 标准 / 硬核）各自的确切数值修正表。
2. 难度选择在开局时定，并进存档。
3. 平衡基线要**按难度各存一份**，否则硬核档会把标准档的断言带红。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（三档数值修正表 + 是否可中途改）并复核。
- [ ] **A2** 断言：三档下 `balance_check` **各自**在容差内（基线按难度分开）。
- [ ] **A3** 断言：难度只改数值 —— 规则级断言（结算 / 存档 / 遭遇分派）在三档下**行为一致**。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若三档维护成本过高，先做「标准 + 硬核」两档。
