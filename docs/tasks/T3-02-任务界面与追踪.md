## 目标

- 任务要在界面上看得见、追得到，否则玩家不知道自己在干什么。

## 实现要点

1. 任务列表（进行中 / 已完成）、当前追踪目标、剩余时限。
2. HUD 上一条常驻追踪（不许遮挡既有 HUD 元素）。
3. 文案全部进 `Strings.gd`（`ui_total` 基线 0 不许破）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（界面分区 + 追踪条位置 + 显示字段）并复核。
- [ ] **A2** 门禁一步断言：列表内容、追踪切换、时限显示、空列表不报错。
- [ ] **A3** `i18n_check` 的 `ui_total` 仍为 0；人工核查 1600×900 截图无重叠。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若 HUD 版面不够，追踪条并入任务面板（不做常驻显示）并记明。
