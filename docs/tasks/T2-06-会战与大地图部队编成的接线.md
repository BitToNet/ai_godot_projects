## 目标

- 遭遇 → 会战 → 伤亡 → 回写大地图，这条链现在只对 Boss 单体成立。
- 把「打谁 / 带谁 / 死多少 / 得什么」全接上，阶段二的闭环才算闭合。

## 实现要点

1. 遭遇入口按对手类型分派：单体 Boss 战 vs 小兵会战。
2. 伤亡、战利品、经验、声望的回写要**单一入口**，避免两处各算一遍。
3. 撤退 / 买路 / 索要买路钱（既有四条路）在会战下也要成立。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（分派规则 + 回写字段 + 四条路的会战语义）并复核。
- [ ] **A2** `encounter_check` 扩展断言：两条路都能进、伤亡与战利品回写一致、撤退在会战下不卡死。
- [ ] **A3** 存档往返：会战后存读档，兵力 / 经验 / 物品一致。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退
