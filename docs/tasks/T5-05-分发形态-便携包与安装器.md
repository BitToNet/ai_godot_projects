## 目标

- 决定并实现「玩家怎么拿到游戏」：便携 zip、安装器，还是商店直接上传。
- 这决定目录结构（存档路径 / 配置路径是否要写进用户目录）。

## 实现要点

1. 目录结构固定：可执行 + `pck` + 授权文件（`ATTRIBUTION.md` / `LICENSE.txt` 必须随包分发）。
2. 存档与配置路径要与分发形态解耦（便携版不许往程序目录写用户数据）。
3. 打包脚本可复现。
