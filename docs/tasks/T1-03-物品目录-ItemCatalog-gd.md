## 目标

- 需要一个「东西」的定义：武器 / 护甲 / 饰品 / 消耗品，含基准价、数值修正、适用槽位。
- 目录必须**数据驱动且可断言**，而不是散落在代码里的 if。

## 实现要点

1. `ItemCatalog.gd`：`Item` 定义 + 静态目录表。字段：id / 名称 i18n key / kind（weapon·armor·trinket·consumable）/ 基准价 / 数值修正 / 适用槽位。
2. **显示名一律存 i18n key**，不存中文；`Strings.gd` 提供 `item_name(id)`。
3. 目录里存**基准价**；繁荣度定价修正属于商店（T1-06），不写进目录。
4. 目录表本身要能被断言：id 唯一、kind 合法、基准价 > 0、槽位与 kind 匹配。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** `character_check` 断言目录完整性（id 唯一 / kind 合法 / 基准价 > 0 / 槽位匹配）。
- [ ] **A2** 门禁全绿；`i18n_check` 的 `ui_total` 仍为 **0**；`scripts/core` **不新增硬编码中文**。
- [ ] **A3** 生成指纹与统计一字不变。

## 回退

- 若 `Resource` 目录让加载期依赖变重，退化为纯静态字典 + 枚举。
