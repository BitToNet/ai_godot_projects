## 目标

|- **口径已定（决策 9）：1080p60**（1920×1080 / 稳定 60 FPS ⇒ 帧预算 ≤16.6 ms）；本节所有数字都按这个口径测。
- ④ 的唯一硬前置：**先量实时帧率**。
- 现有全部性能数字都是 headless（`--fixed-fps`），**不能代表真实渲染**；在不知道真实帧率的情况下做 ④ 的优化等于蒙。

## 实现要点

|1. 必须用**真窗口 + 1920×1080** 跑（不能 headless）；注意失焦时 Godot 会降帧甚至停帧，所以要么保持聚焦、要么写清用了什么手段 —— **测法必须写在结果里**。
2. 至少四个机位：战略视图远景 / 大地图近景 / 村庄机位 / 城镇机位 / 城堡机位，另加「100 支部队同时在场」场景。
3. 记录：平均帧、1% low、draw call、可见顶点数；与 60 fps 预算对照。
4. **本次只测量、不下断言**（与 `big_map_probe` 同一纪律）。
