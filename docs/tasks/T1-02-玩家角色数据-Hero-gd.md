## 目标

- 玩家现在有钱袋与声望，但**没有「自己」这个实体**：没有等级、装备、属性。
- ⑤「变强」闭环的第一块，就是把玩家变成**可成长的数据对象**。

## 实现要点

1. `Hero.gd` 用 `Resource`（与 `EconomyRules` / `EncounterRules` 同风格，**数值进 Resource**）：等级 / 经验 / 技能点 / 装备槽（武器 · 护甲 · 饰品）/ 派生属性（攻击 · 防御 · 最大 HP · 速度修正）。
2. **属性汇总必须单一入口**：`Hero.stats()` 返回只读字典，战斗与 UI 都从这里读 —— 不许各自算一遍（本仓库踩过「中文名表重复三份」的坑）。
3. **默认值必须与今天逐位一致**：不装任何装备时，战斗数值与当前硬编码值完全相同。
4. `CampaignState` 增加 `hero`，并纳入存档序列化（T1-09）。
