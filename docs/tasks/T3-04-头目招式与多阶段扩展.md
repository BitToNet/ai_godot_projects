## 目标

- 现在 Boss 只有两阶段且招式少；战斗时长与变化不足。
- 「打更强」需要更强的对手，否则 ⑤ 的成长没有对手承接（E1）。

## 实现要点

1. 头目按势力 / 等级给不同招式组；阶段切换有明确触发与提示（沿用既有前摇预警范式）。
2. 招式必须**可学习**（有可读前摇），不做无解招。
3. 与 T2-01 的玩家招式表对称设计（同一套数据驱动思路）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（招式表 + 阶段触发条件 + 每个招式的可应对方式）并复核。
- [ ] **A2** 断言：每个招式都能被触发到（脚本化跑一遍覆盖）；阶段切换正确。
- [ ] **A3** 断言：每个招式有可用的应对（闪避 / 弹反 / 拉开），没有无解招。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若招式过多导致 AI 稳定性下降，先按势力各 3~4 招并记明。
