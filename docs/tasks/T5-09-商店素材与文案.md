## 目标

- 上架要有素材：截图、预告、简介、特性列表 —— 这些也要从**实际画质**出，不能修图骗人。
- 素材准备会反向暴露画质短板（比如农场色块发白那类欠账）。

## 实现要点

1. 截图集（不同地貌 / 天气 / 战斗 / 会战 / 面板各若干张）按目标渠道尺寸出。
2. 预告片与简介；特性清单要**只写已实现**的。
3. 素材里出现的画面必须与出货版本一致（不许用调试模式下的画面冒充）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（素材清单 + 渠道尺寸要求）并复核。
- [ ] **A2** 截图与预告全部来自**出货版本**的实际运行（记录出处与机位）。
- [ ] **A3** 特性清单逐条能在游戏里复现（人工核查）。
- [ ] **A4** 素材入库到 `docs/store/` 并列入 `.gitignore` 例外（大文件策略需先定）。

## 回退

- 若画质达不到宣传要求，先只出截图不出预告片，并把画质缺口回写成新任务卡 —— **不要修图掩盖**。
