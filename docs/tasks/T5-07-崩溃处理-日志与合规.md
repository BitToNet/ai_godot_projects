## 目标

- 发布版不能把错误栈丢给玩家，也不能悄悄上传数据。
- E7「商业合规」：本项目**不收集任何用户数据**是最省事的合规立场，要明确写下来并保证代码做到。

## 实现要点

1. 未捕获错误 / 崩溃时给出可读提示与本地日志路径（日志不自动上传）。
2. 明确声明不收集数据；若将来要收集，必须单独一轮并写隐私政策。
3. 第三方许可（4 个 CC0 GLB + 音频素材）在游戏内可查看（合规常见要求）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（崩溃处理行为 + 日志位置 + 合规声明）并复核。
- [ ] **A2** 断言 / 人工核查：模拟损坏存档与资源缺失时不崩且有可读提示。
- [ ] **A3** 游戏内可查看第三方许可与来源（人工核查截图）。
- [ ] **A4** 确认代码中**没有任何**网络上报调用（静态核查，写进记录）。

## 回退

- 若崩溃提示影响正常体验，退化为「静默写本地日志 + 提供日志入口」；但**资源缺失与坏存档这两条必须仍有可读提示**。
