## 目标

- 现在的世界是永恒晴天中午，E2 的「内容量」在观感上很单薄。
- 天气 / 季节是最低成本提升世界可信度的一项。

## 实现要点

1. 天气状态机（晴 / 雨 / 雾 / 雪）+ 季节（植被色 / 雪线）。
2. 必须**可关**（`MapConfig` 开关）—— 门禁与探针需要确定的环境。
3. 昼夜与天气的交互不能破坏既有观感（农场色块发白、夜里不暗等欠账要一起看）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（状态机 + 视觉参数 + 开关）并复核。
- [ ] **A2** 断言：天气状态机可复现（固定种子 ⇒ 固定序列）；关掉后与今天**完全一致**。
- [ ] **A3** 人工核查：四种天气 + 季节各出一张同机位截图，确认无穿帮。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若天气影响生成确定性，天气一律走**表现层**（不改高度场 / 植被布局），并在本卡写死这条。
