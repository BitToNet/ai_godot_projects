## 目标

- E2 要求 ≥6 类敌人；现在只有 3 类头目（领主 / 商队 / 强盗）。
- 敌人种类是「战斗是否耐玩」的第一决定因素。

## 实现要点

1. 每类敌人有自己的**行为模式**（不是换皮）：攻击距离 / 节奏 / 弱点 / 应对方式。
2. 与遭遇定式联动：不同敌人给出不同的四条路（买路价格 / 可不可以打）。
3. 每类都要有可断言的胜利条件与 AI 决策分支。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（≥6 类敌人的行为表 + 遭遇选项表）并复核。
- [ ] **A2** 每类敌人各有一条断言（进入战斗、AI 分支可达、可被击败、结算正确）。
- [ ] **A3** 性能：最重的敌人组合下有实测帧率（对齐 T1-14 测法）。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若某类敌人做不出差异化，宁可不做（保持 5 类）也不加换皮敌人 —— 并在本卡记明。
