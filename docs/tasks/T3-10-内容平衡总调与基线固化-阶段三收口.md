## 目标

- 阶段三一口气加了任务 / 敌人 / 三条胜利路径 / 天气 / 地标，平衡一定会歪。
- 收口时做一次总调，并把可观测量固化成基线。

## 实现要点

1. 一局完整通关的时长与难度曲线要落在目标区间。
2. 三条胜利路径**都要可达成**（脚本化各跑一次）。
3. 平衡基线固化，超容差判失败。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 三条胜利路径各有一条**脚本化通关**断言（不是人工试玩）。
- [ ] **A2** 一局通关时长有实测数字，落在设计区间内。
- [ ] **A3** 平衡基线固化并进门禁；人为改坏数值必须报红。
- [ ] **A4** 门禁全绿；`README` / `PLAN.md` §B 数字回填。
