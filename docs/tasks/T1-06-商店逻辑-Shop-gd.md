## 目标

- 玩家的钱要有去处：在定居点买东西，把「打 → 赚 → 变强」接成闭环。

## 实现要点

1. `Shop.gd`：库存（按定居点 kind 与繁荣度生成）/ 定价（`EconomyRules` 繁荣度修正 + 买价与卖价差）/ 结算（扣钱、进物品栏、扣减定居点库存）。
2. **不许反向引用**：`SettlementSystem` / `SelectionSystem` 不许持有 `ctx.settlements` 这类回引 —— RefCounted 引用环会导致 RID 泄漏，本仓库踩过。
3. 库存刷新要有**确定规则**（按世界时间 / 天数）且可断言。
4. 与 `CampaignState` 的钱袋 / 军费联动一致：**不许出现两套钱**。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** `tools/shop_check.gd` 断言：定价公式形状、买 / 卖结算、钱不够被拒、库存扣减、刷新规则、边界（空库存 / 编制已满）。
- [ ] **A2** 门禁全绿，项数 +1。
- [ ] **A3** `economy_check` 仍全绿（经济定式未被破坏）。
- [ ] **A4** 生成指纹与统计一字不变。

## 回退

- 若库存刷新引入时间依赖导致定式不稳，改为「进城即按天差补算」的纯函数式刷新（可断言）。
