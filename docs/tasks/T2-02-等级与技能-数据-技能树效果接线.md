## 目标

- ⑤ 的「变强」目前只到装备；还需要**成长本身**：打赢 → 涨经验 → 升级 → 点技能。
- 这是「打 → 赚 → 变强 → 打更强」里最后一段的正反馈来源。

## 实现要点

1. 经验来源与曲线（战斗胜利 / 任务 / 以少胜多），升级阈值与技能点发放。
2. 技能树：至少两条路线（如 武艺 / 统率），每个技能是**可断言的数值修正**，不是纯文案。
3. 技能效果统一走 `Hero.stats()` 的修正管线（T1-02 已立的单一入口）。
4. 面板加「技能」页；文案进 `Strings.gd`。
