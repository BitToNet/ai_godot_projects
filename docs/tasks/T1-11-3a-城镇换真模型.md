## 目标

- ③-2 只把**村庄**换成了真模型（9 村 / 72 栋）；城镇与城堡仍是程序化盒子，风格不统一。
- 本任务把**城镇**换掉，是与村庄同款做法的重复验证。

## 实现要点

1. 照 ③-2 的路子：布局表 + `_place_one()`（角度分槽 + 内切半径判据）+ **全有或全无**回退。
2. **程序化路径一字不改**（RNG 抽取顺序保持原样）⇒ 几何不进指纹，**无需重基线**（§17.5 已证）。
3. 新模型必须 **CC0 且许可清晰**，来源逐文件写进 `ATTRIBUTION.md` + `LICENSE.txt`。
4. 参考项目仓库 `F:\aigc_code\godot_ai_test` 保持**只读**（PORTING §二十三 的既有授权范围）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** `asset_check` 扩展断言：城镇布局落位（模型数、包围盒、无重叠、全有或全无回退生效）。
- [ ] **A2** 人工核查：`visual_shot.gd --focus=town` 出图，确认与村庄**风格统一**、无穿插 / 悬空。
- [ ] **A3** 门禁全绿，且**生成指纹 `958433c2…` 一字不变**（几何不进指纹；变了说明碰了 RNG 抽取，停下来查）。
- [ ] **A4** `scale_probe` 结构量基线不变（实例数 / 区块数 / 变换指纹）。

## 回退

- 若找不到许可清晰的 CC0 城镇套件，先只换主体建筑（主堡 / 市场），其余留程序化并在本卡记明。
