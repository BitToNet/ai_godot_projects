## 目标

- 现在 `Strings.gd` 是 GDScript 常量表，只有中文；E6 要求可切换语言。
- 先把**管道**搭起来（CSV → 引擎翻译 → 取词），再迁文案。

## 实现要点

1. 建 `i18n/strings.csv`（key / zh / en），`Strings.gd` 改成查表但**保持同一套 API**（调用方不感知）。
2. 缺失翻译要么回退中文，要么在 `i18n_check` 里报出 —— 不许静默显示 key。
3. 既有 `i18n_check` 的棘轮语义要保留（硬编码中文只许变少）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（CSV 字段 + key 命名规则 + 回退策略）并复核。
- [ ] **A2** `i18n_check` 扩展断言：CSV 与 `Strings.gd` 的 key 集合一致、无重复、无空译文（或明确允许回退）。
- [ ] **A3** 断言：切换语言后取词真的变（至少抽 10 个 key 验证）。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若 CSV 导入在 headless 下不稳，先保留 `Strings.gd` 为唯一来源并生成 CSV（单向），记明。
