## 目标

- 给「变强」一个**看得见**的界面：属性 / 装备 / 物品栏。
- 玩家必须能自己完成「捡到更好的武器 → 换上 → 数值变了」这一串操作。

## 实现要点

1. 按现有 UI 的既有风格做（`SettlementDialog` / `SelectionPanel`），复用 `Theme.tres`；**键盘与手柄都要能操作**（`InputMap` 新增动作，界面上的键位文字从 `InputMap` 现读，不许手写）。
2. 文案**全部**进 `Strings.gd` —— `scripts/ui` 的硬编码中文棘轮基线当前是 **0**，不许破。
3. 装备操作：装上 / 卸下；非法操作要有**原因提示**（沿用「灰条目带原因」的既有范式）。
4. 与世界时间的交互按现有约定（与遭遇对话框一致：打开即暂停）。
