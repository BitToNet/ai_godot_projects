## 目标

- E5「外壳完备」的第一项：现在启动直接进游戏，**没有主菜单**。
- 「继续游戏」还依赖它才能有落点。

## 实现要点

1. 新开局（可选种子）/ 继续（读最近档）/ 设置 / 退出。
2. 「继续」在无存档时灰掉并给原因。
3. 主菜单不能破坏既有启动路径：门禁与探针仍要能 **headless 直接进主场景**（不许强制过菜单）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（菜单项 + 无存档时的状态 + 启动路径）并复核。
- [ ] **A2** 断言：主菜单能开、四项可跳转、无存档时「继续」被灰掉且有原因。
- [ ] **A3** 门禁全绿（**既有 headless 入口不被菜单拦住** —— 这条是硬要求）。
- [ ] **A4** `i18n_check` 的 `ui_total` 仍为 0；门禁全绿。

## 回退

- 若主场景切换影响门禁，用命令行参数绕过菜单（既有 `--` 传参范式）。
