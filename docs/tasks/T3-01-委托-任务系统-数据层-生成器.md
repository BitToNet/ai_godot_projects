## 目标

- 现在玩家没有「被要求做的事」，只有自发的打与买 —— 缺少把玩家推向地图各处的牵引力。
- 委托是 E2「内容量够一次完整游玩」最直接的来源（送信 / 剿匪 / 护送）。

## 实现要点

1. `QuestDef`：类型 / 目标 / 时限 / 奖励 / 失败条件；`QuestLog` 存进行中与已完成。
2. 生成器用现有 `NameForge` + `AIParty` 造具体委托（不写死 20 条文案）。
3. 生成必须**确定性**（独立 RNG 流，不许混进地图生成流）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（三类委托的目标与失败条件、奖励公式、生成规则）并复核。
- [ ] **A2** `quest_check` 断言：生成确定性、时限推进、完成 / 失败判定、奖励结算。
- [ ] **A3** 存档往返：进行中委托存读档后一致（含剩余时限）。
- [ ] **A4** 门禁全绿；生成指纹与统计一字不变。

## 回退

- 若生成器反馈不佳，先做「固定模板 + 随机参数」而不是全生成。
