## 目标

- 到这一步为止，**所有验证都是我自己跑的**；E4 要求「外部测试」。
- 陌生玩家会在 10 分钟内暴露我们看不见的问题（教程、引导、性能、崩溃）。

## 实现要点

1. 至少 3 名未接触过项目的人试玩，记录卡点 / 崩溃 / 困惑点。
2. 明确观察指标（能否在无提示下完成：进城 / 买东西 / 存档 / 打赢一场）。
3. 反馈要变成**任务卡**或明确「不做」的理由，不许只留一份记录。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（测试人数 + 观察指标 + 记录模板）并复核。
- [ ] **A2** 至少 3 人完成测试，记录存档在 `docs/`。
- [ ] **A3** 每条反馈都有处置结论（修 / 不修 + 理由）。
- [ ] **A4** 崩溃与卡死类问题**全部**修掉或有明确规避说明。

## 回退

- 若凑不到 3 名外部测试者，把人数降到 2 并**明确记明这是降低标准** —— 不许用内部自测冒充外部测试。


## 待决问题（开工前先答）

- 测试者从哪来？（需要用户提供或授权招募方式。）
