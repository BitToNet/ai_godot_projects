## 目标

- 现在 AI 部队在动，但**势力没有目标**：不会扩张、不会结盟、不会因为被打而报复。
- 世界要「活」，先要势力有目标函数 —— 这是 E1「对手会变强」的地基。

## 实现要点

1. 每个势力一个目标：扩张 / 守成 / 通商 / 复仇；用**可断言的评分函数**选行动（不许随机漫步）。
2. 决策频率与时间尺度要和世界时间（暂停 / ×1×2×4）对齐。
3. 决策必须**确定**：同一种子 + 同一世界时间 ⇒ 同一决策（可断言，沿用 RNG 分流的既有纪律）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（目标函数 + 评分项 + 决策频率）并复核。
- [ ] **A2** `campaign_check` 断言：同种子同时间 ⇒ 决策序列**逐位可复现**。
- [ ] **A3** 断言四个势力的行为差异确实存在（不是都做同一件事）。
- [ ] **A4** 门禁全绿；生成指纹与统计一字不变（决策用独立 RNG 流，不许混进生成流）。

## 回退

- 若确定性难以保证，把决策降级为「按固定节拍重算的纯函数」并在本卡记明。
