## 目标

- ③-3a / ③-3b 换完模型后，**显式**重基线一次 —— 这是 §16.4 立下的纪律：同一件事不要在两次重基线里各付一遍。
- 并回答 PORTING §二十一 留下的唯一问题：**真模型覆盖后，程序化构造器留不留？**

## 实现要点

1. 重基线必须是**显式接受**的动作（`--write-baseline`），提交信息写明重基线原因与范围。
2. 重基线前先**记录旧值**，提交里贴出旧值 → 新值的 diff（证明只是几何 / 性能变了）。
3. **指纹不该变**。若 `gen_fingerprint` 变了，说明碰了 RNG 抽取顺序 ⇒ **停下来查**，不许顺手重基线指纹。
4. 决策「程序化构造器去留」：留（作全有或全无回退路径，`asset_check` 已覆盖）vs 删（减代码与分支）。给出结论 + 理由。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 门禁全绿；`scale_probe` / `perf_probe` 与新基线一致。
- [ ] **A2** 生成指纹与 1024 m 存档**逐字节一致**（本任务不得修改指纹）。
- [ ] **A3** 人工核查：提交信息 / 本卡里能看到旧值 → 新值的**显式 diff**。
- [ ] **A4** 「程序化构造器去留」有明确结论，写进本卡并同步 `docs/PLAN.md` §D。
