## 目标

- 把 `Shop.gd` 变成玩家真能操作的界面：看见货、看见价、买得起就买、买不起要说为什么。

## 实现要点

1. 与 `SettlementDialog` 同风格，复用 `Theme.tres`；键盘与手柄都能操作，界面上的键位文字**从 `InputMap` 现读**。
2. 买入 / 卖出两侧布局；**繁荣度带来的价格差异要能看见**（否则玩家不知道去哪买便宜）。
3. 买不起 / 库存为 0 的条目**灰掉并给原因**（沿用既有范式）。
4. 文案全部进 `Strings.gd`；打开面板时世界时间按既有约定暂停。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 门禁一步断言：面板开 / 关、买入、卖出、钱不够被拒且有原因、库存为 0 被灰掉。
- [ ] **A2** `i18n_check` PASS 且 `ui_total` 仍为 **0**。
- [ ] **A3** 人工核查：`tools/ui_shot.gd` 出 1600×900 截图，确认无重叠 / 无截断，价格与理由都能看清。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若两侧布局在 1600×900 下太挤，退化为单列列表 + 数量选择器，并在本卡记明。
