## 目标

- 现在 Boss 战是**一对一单体**，玩家带多少兵都不影响战斗。
- 带兵打仗是这个题材的核心；没有小兵会战，「统率」类成长与部队编成就是空的。

## 实现要点

|1. 轻量单位：复用 Boss 的状态机骨架但**大幅简化**（少状态、少动画），目标是 20~50 个同屏在 **1080p60**（决策 9）下有富余。
2. 编成影响战场：玩家部队数量 / 兵种决定己方单位数与强度。
3. 战斗结算要与大地图部队兵力**一致**（不许打完不回写）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（单位状态机 + 同屏上限 + 性能预算 + 结算回写规则）并复核。
- [ ] **A2** `melee_check` 断言：N 个单位同屏时结算正确、兵力回写一致、无单位卡死。
- [ ] **A3** 性能：同屏目标数量下有实测帧率（对齐 T1-14 的测法）。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。

## 回退

- 若同屏性能不达标，先降到 10~15 个单位并记明，不要为了数字硬撑。
