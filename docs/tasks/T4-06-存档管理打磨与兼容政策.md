## 目标

- T1-10 交付了多槽 / 自动存档 / 确认的**逻辑**；本任务做 UI 打磨与**长期兼容政策**。
- 一旦发布，存档兼容就是承诺，必须写死规则。

## 实现要点

1. 槽位缩略信息（时间 / 等级 / 天数 / 位置）、删除与覆盖、排序。
2. 兼容政策：v1 只读；未来版本必须能读**至少上一个大版本**；升级时自动迁移并强制另存。
3. 写到 `docs/PLAN.md`（政策是长期约定，不是代码注释）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（槽位信息字段 + 兼容政策条文）并复核。
- [ ] **A2** `save_check` 扩展断言：槽位信息正确、删除与覆盖生效、自动迁移路径可跑。
- [ ] **A3** 政策条文已写进 `docs/PLAN.md` 并在本卡引用。
- [ ] **A4** `ui_total` 仍为 0；门禁全绿。

## 回退

- 若自动迁移的实现成本过高，先把兼容承诺缩小到「上一版本可读」，并在政策条文里同步缩小（不许承诺大于实现）。
