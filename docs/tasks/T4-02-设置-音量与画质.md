## 目标

- 现在只有 `AudioConfig` 里的 `@export` 常量，玩家改不了音量与画质。
- E5 要求设置界面；这是商业级最基本的一项。

## 实现要点

1. 音量：主 / 音效 / 音乐三档，**接到既有 `AudioBus`**（不许另起一套音量计算 —— 既有权重「总音量只算一次」是定式断言）。
2. 画质：植被密度、视距、阴影、SSAO / glow 开关（既有 GPU 成本未测，见欠账）。
3. 设置要**持久化**到 `user://`（不是存档，独立配置文件）。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 设计稿先写进本卡（设置项清单 + 取值范围 + 默认值 + 落盘格式）并复核。
- [ ] **A2** 断言：设置写入后重启仍在；音量改动确实影响 `AudioBus`（既有 4g 定式仍绿）。
- [ ] **A3** 断言：画质档位切换后植被实例数 / 视距确实变化，且**不触发地图重新生成**（不许变成重生成）。
- [ ] **A4** 门禁全绿；`ui_total` 仍为 0。

## 回退

- 若画质项过多，先交付音量 + 植被密度 + 视距三项，其余记明。
