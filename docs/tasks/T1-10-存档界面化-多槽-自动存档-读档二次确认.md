## 目标

- 现状是**单槽 + 读档无确认**（README 已把它写进「已知限制」）：按一下 F9 就覆盖当前进度。
- 本任务把它变成：多槽 + 自动存档 + 读档 / 覆盖有确认 + 损坏档不崩。

## 实现要点

1. 槽位模型：手动 N 槽 + 1 个自动槽（轮换）；F5 / F9 保留为「快速存 / 读」但语义与 UI 一致。
2. 读档与覆盖都要**二次确认**；确认流程要能被脚本化模拟（含「取消」分支）。
3. 损坏档：明确提示、不崩、不影响其它槽。
4. 文案全部进 `Strings.gd`；界面按现有 UI 风格。

## 验收标准

> 每条都要能**执行**并给出通过 / 不通过。无法机器判定的，写进「人工核查」并写清看什么。

- [ ] **A1** 门禁一步断言：多槽读写、自动存档轮换、损坏档不崩且有提示、确认流程可取消。
- [ ] **A2** 扩展 `save_check`：多槽互不污染（写 A 槽不影响 B 槽）。
- [ ] **A3** `i18n_check` PASS 且 `ui_total` 仍为 **0**；人工核查截图。
- [ ] **A4** 门禁全绿；指纹与统计一字不变。
