# 玩法规格：《骑马与砍杀》式战略大地图 + 2D Boss 决斗

> **这份文档是「玩法层」规格书**，用途是把当前原型里的玩法原样迁移到另一个引擎 / 另一个项目：
> 把整份文档当作给接手 AI 的提示词即可，它描述了**玩家能看见、能操作、会被数值影响的一切**，
> 以及这些设计**为什么**这样定。
>
> 三条阅读约定：
> 1. **数值分两类**：`【骨架】` = 改了会破坏经济 / 难度结构的量，迁移时应原样保留；
>    `【可调】` = 手感与节奏参数，允许在目标项目里微调（但改完要重跑第 15 节的验收）。
> 2. **单位**：大地图 1 单位 = 1 米；Boss 战 1 单位 = 1 像素（玩家身高 64 px ≈ 1.7 m）。
>    两套单位不要混用，迁移时可在战斗里改成「米」但数值比例要保持。
> 3. **时间**：大地图 1 游戏日 = 120 秒现实时间（×1 流速）；Boss 战内一律用真实秒。
>
> 本文**不**描述渲染、网格生成、着色器、音频合成、文件组织 —— 那些见 [README.md](../README.md) 与
> [ARCHITECTURE.md](ARCHITECTURE.md)；本文末尾第 14 节专门列出「**不要顺手补全**」的部分。

---

## 0. 给接手 AI 的元指令（先读这段）

- **目标形态**：单机、单人视角、无联网、无内购。玩家扮演一支小型佣兵部队的队长，在一张
  **程序化生成**的战略大地图上移动、遭遇、交战、进城补给与交易，战斗以 **2D 横版单挑** 呈现。
- **必须原样保留的骨架**：
  1. 核心循环（第 2 节）；
  2. 时间流动 / 暂停规则（第 4 节）—— 这是整个大地图手感的来源；
  3. 遭遇四选项及其门槛与代价（第 8 节）；
  4. 战役经济公式（第 7 节）与进城菜单的服务差异（第 9 节）；
  5. Boss 战的招式骨架、三档敌人差异、弹反 / 闪避 / 破防循环（第 10 节）；
  6. 战果结算（第 11 节）。
- **可以自由重构**：地图生成算法、渲染方式、UI 布局细节、音频资源、存档格式。
- **界面语言**：面向玩家的全部文本使用**中文**；禁用条目必须给出「为什么不能点」的理由
  （第 13 节），不允许静默失败。
- **不要做的事**：不要加小兵会战、不要加技能树 / 装备 / 等级、不要加多存档槽、不要加主菜单与设置
  界面、不要让 AI 互相开战 —— 这些是**当前刻意的取舍**（第 14 节），未经新需求不要"顺手补全"。
- **验收方式**：按第 15 节的清单逐条过；附录 A 的数值表能对上，即视为迁移成功。

## 1. 一句话概念与玩家幻想

> **你带着 37 个人和 400 枚银币，走在一张 1 公里见方的战争地图上：粮要钱、兵要钱、命也要钱。
> 打商队最肥，打强盗最稳，打领主最险。想活下去，就得算清楚下一场仗值不值。**

三个体验支柱：

| 支柱 | 玩家感受 | 由什么机制支撑 |
|---|---|---|
| **「骑砍式」时间控制** | 世界默认是停的，我想让它走它才走；路上撞见谁，时间立刻冻住让我做决定 | 时间流动状态机 + 赶路自动流动 + 遭遇强制暂停（第 4、8 节） |
| **算账的紧张感** | 每周发薪、每天吃粮，钱只出不进，必须主动去挣 | 周薪 / 口粮 / 士气 / 逃兵闭环（第 7 节） |
| **决斗的硬碰硬** | 兵力是"血条"，但每一刀都得自己打；弹反成功的那一刀特别爽 | 2D 横版 Boss 战（第 10 节） |

**参考坐标**（用于对齐手感，不是要求复刻）：战略层 =《骑马与砍杀》的大地图 + 部队遭遇；
战斗层 =《神之天平（ASTLIBRA）》的横版单挑节奏（前摇可读、弹反、闪避无敌帧、破防）。

## 2. 核心循环

### 2.1 一次循环（约 3–6 分钟）

```
① 看地图，决定去哪（点地面 → 部队自动寻路，世界时间开始流动）
        ↓
② 路上撞见 AI 部队 → 时间冻住 → 遭遇菜单：【攻击 / 买路 / 索要 / 撤退】
        ↓                                     ↘ 不打算打：撤退或买路，付代价继续走
③ 选「攻击」→ 进入 2D 横版 Boss 战（1–3 分钟）
        ↓
④ 结算：胜利拿战利品 + 声望，按类型损失兵力；战败掉兵掉钱被送回城
        ↓
⑤ 走到定居点旁 → 按键进城：买补给 / 招兵 / 买卖货物 / 存驻军
        ↓
⑥ 时间继续推进 → 每天吃粮、每 7 天发薪 → 士气低到 20 以下开始逃兵
        ↓
⑦ 回到 ①：钱变少 → 必须再打一场 / 再做一趟买卖
```

### 2.2 三种节奏叠在一起

| 尺度 | 内容 | 时长 |
|---|---|---|
| **秒级** | 一刀的前摇 / 弹反窗口 / 闪避无敌帧 | 0.1–0.6 秒 |
| **分钟级** | 一场 Boss 战、一次进城办事、一段赶路 | 1–3 分钟 |
| **「周」级** | 发薪周期（7 天 = 14 分钟现实时间）、志愿者回流（2 天）、升档攒钱 | 10–30 分钟 |

### 2.3 失败螺旋（**必须保留**的设计）

经济是**负向默认**的：不做事就会慢慢死。断粮 → 士气崩 → 逃兵 → 兵力少 → 打不过 → 更没钱。
玩家唯一的出路是**主动出击或做生意**。这是整个游戏的张力来源；如果把收入调高到"躺着也能活"，
核心循环就废了。

反过来，成长也是真实的：**钱 → 兵 → 兵力即血量 → 打得动更硬的敌人 → 更多战利品**，
以及 **声望 → 领导力 → 编制更大 / 军费更便宜 / 买路钱打折**。

## 3. 世界与地图（战略层）

### 3.1 尺寸与确定性

| 项 | 值 | 说明 |
|---|---|---|
| 地图尺寸 `【骨架】` | **1024 m × 1024 m** | 正方形。目标项目可放大，但所有"米"为单位的玩法量要按倍率推导（见 3.6） |
| 世界种子 | `20250929` | 同一种子 ⇒ 同一张地图、同一批定居点、同一批部队、同一套物价 |
| 高度场分辨率 | 513 × 513（格距 2 m） | 只影响地形精度，不影响玩法 |
| 海平面 | 0 m | 低于海平面的地方是水，部队不可通行（浅滩除外） |
| 生成耗时 | 约 3 秒（1024 m） | 期间显示 Loading 遮罩；这不是玩法，但如果目标项目生成更慢要给出进度反馈 |

**确定性要求**：每个子系统使用**独立的随机流**，由「种子 + 子系统标签」派生。
好处是：改一个子系统不会改变另一个子系统的结果，同一张图每次启动完全一致。
（例：定居点经济用 `"settlement_economy"` 流；部队生成按「种子 + 序号 × k」派生。）

### 3.2 地形与地貌

- 大陆是一块**偏移到东北方的圆形大陆**（中心约在地图 60% / 36% 处，半径约 70% / 64% 的地图宽），
  海岸线由分形噪声打碎，并被 **3 个圆形海湾 / 内海盆地** 切出半岛。
- **山脉是显式条带**（4 条线段，每条有「宽度 = 缓坡范围」「高度 = 山体高度」两个参数），
  不是纯噪声堆出来的：这样山脉走向可读、山口位置稳定，行军路线才有意义。
- 高度合成：山体振幅 62 m、丘陵 17 m、基底 13 m、沙漠 8 m、细节 2 m，平滑 3 遍。
  岩石线 ≈ 88 m，雪线 ≈ 118 m。
- **水体**：2 条河（河宽 22 m、下切 7 m）、1 个湖（半径 46 m、深 9 m）、每河 2 处浅滩（可涉水）。
- **植被是纯装饰**（约 2.4 万株：针叶 8000 / 阔叶 10000 / 仙人掌 1600 / 枯树 1000 / 岩石 3200），
  **不参与碰撞、不阻挡行军**。森林由噪声成片（阈值 0.52），陡坡（>0.46）不长树。

> 为什么保留"植被只是装饰"：部队贴地靠采样高度场，不加物理碰撞体是性能取舍（第 14 节）。

### 3.3 势力与定居点

| 项 | 值 |
|---|---|
| 势力数 | **3**（各有自己的名字与颜色，颜色用于 UI 与地面旗帜） |
| 每势力定居点 | **1 座城堡（王都）+ 2 座城镇 + 3 座村庄** ⇒ 全图 **18 座** |
| 最小间距 | 96 m（保证两座定居点之间"要走一段路"） |
| 道路 | 沿地形连接定居点（半宽 4.5 m），过河自动架桥（1024 m 图上约 5 座桥） |
| 地基平整 | 每座定居点周围 26 m 半径内地形抹平，保证建筑不悬空 |

**三类定居点的定位（`【骨架】`，直接决定玩法）**：

| 类型 | 名称后缀 | 重要度 | 繁荣基准 | 初始驻军 | 志愿者上限 | 能提供的服务 |
|---|---|---|---|---|---|---|
| 城堡 | 王都·城堡 | 1.00 | 70 ± 25 | 180–320 | **0（不招兵）** | 补给、驻军 |
| 城镇 | 城镇 | 0.80 | 56 ± 25 | 80–170 | 20 | 补给、招募、贸易、驻军 |
| 村庄 | 村庄 | 0.55 | 38 ± 25 | 12–45 | 12 | 补给、招募、驻军 |

> 设计意图：城堡是"军事据点"（重兵、不招兵，王都只在城堡里），城镇是"市场"，
> 村庄是"兵源地但穷"。玩家前期的行动半径基本由「最近的村庄」决定。

### 3.4 战争迷雾

- 128 × 128 的探索度网格，**探索后永久可见**（没有"回头再探索"的动态可见性）。
- 揭示半径 **118 m**（按地图尺寸线性放大），玩家与所有 AI 部队都会揭开迷雾。
- 迷雾只压暗地形 / 建筑 / 植被的表面颜色；海面与天空不受影响。
- 小地图显示的是「已探索区域 + 定居点 + 部队」，**不支持点击跳转、不能旋转**。

### 3.5 相机（战略层手感）

| 项 | 值 |
|---|---|
| 高度范围 | 20 m（贴近地面，近乎平视）→ 400 m（俯瞰） |
| 默认高度 | 90 m |
| 俯角随高度 | 26°（近）→ 72°（远） |
| 平移 | WASD / 鼠标推屏幕边缘，速度 190 m/s（随高度缩放） |
| 旋转 | Q / E 或鼠标中键、右键拖拽 |
| 缩放 | 滚轮 |
| 回到自己部队 | F |
| 战略视图 | 高度 ≥ 275 m 自动进入：植被整块剔除、定居点与部队标签放大 |

> 这套"越远越俯瞰"的映射让「拉到最远看全局 → 拉近看部队」成为一个连续动作，
> 而不是两个离散模式。

### 3.6 换更大的地图时怎么推导（如果目标项目要更大世界）

固定米数的**视觉量**按 `倍率 = 地图边长 / 1024` 线性放大：相机高度上下限、平移速度、
战略视图阈值、迷雾半径、AI 视野半径、河道宽度、渡口数量、定居点最小间距、地基半径。

**速度与遭遇距离不放大**：玩家 46 m/s、AI 34 m/s、遭遇 7 m 是"模型接触距离"，
放大只会让地图"看起来更大但走起来一样快"。AI 部队数量按 `14 × 倍率^1.42` 增长
（1024 m → 14 支，2048 m → 37 支，4096 m → 100 支），这样大地图不会因为"人太少"而变空。

## 4. 时间流动（「骑砍式暂停」，`【骨架】`）

这是整个大地图最重要的一条规则。世界默认**是停的**。

### 4.1 四个状态

| 状态 | 含义 | 谁让它进入 | 世界是否推进 |
|---|---|---|---|
| `FROZEN` | 暂停（玩家自己停的） | 抵达目的地 / 松开空格 / 手动取消行军 | 否 |
| `MARCHING` | 行军（部队在走） | 点击地面下达移动命令 | **是** |
| `WAITING` | 原地等待（时间在走但人没动） | 部队停下后按住空格 | **是** |
| `LOCKED` | 强制暂停 | 遭遇对话框 / 进城菜单 / Boss 战 | 否（**空格无效**） |

### 4.2 操作语义（这三条必须一字不差地实现）

1. **点地面** → 部队寻路出发 → 自动进入 `MARCHING`（时间开始流动）
   → **抵达目的地的瞬间自动暂停**（`FROZEN`）。
2. **行军途中按空格** → **行军立即中断**，部队就地停下并暂停；这次按键**被消耗掉**
   （继续按住不会又开始流动，必须松开再按）。
3. **部队停下后按住空格** → 时间流走（`WAITING`）；**松开立刻暂停**。

### 4.3 其他规则

- **流速**：`R` 在 **×1 / ×2 / ×4** 之间循环。默认 ×1。
- **时间尺度**：1 游戏日 = 120 秒现实时间（×1）。起始时刻 **08:00**。
  `time_of_day` 归一化到 0–1，跨过 1.0（午夜）时 **天数 +1** 并触发「日结」。
- **暂停世界 = 什么都不推进**：AI 不思考、日结不触发、遭遇不检测。
  但相机、UI、悬停提示照常响应（否则玩家会觉得卡死）。
- **强制暂停（LOCKED）**：遭遇菜单、进城菜单、Boss 战期间，空格**完全不生效**。
  关闭面板后由状态机**重新裁决**：如果部队仍在行军路径上则恢复流动，否则保持暂停。
- **AI 在暂停时完全不思考**（连寻路请求都不发），这是性能红线。

> 常见 bug（迁移时注意别踩）：撤退 / 关闭面板后如果只是"重新评估一次"而不解锁，
> 时间会永久冻死 —— 旧实现踩过这个坑。关闭面板必须走「解锁」，再让状态机决定流不流。

## 5. 部队、移动与 AI

### 5.1 玩家部队

| 项 | 值 |
|---|---|
| 初始兵力 | **37 人**（`【骨架】`，与后面所有公式耦合） |
| 出生点 | 王都旁 18 m / 26 m 偏移处 |
| 移动速度 | **46 m/s**（战略地图尺度） |
| 寻路 | 4 m 细栅格 A*（玩家） |
| 标签 | 「玩家部队 · N 人」 |

### 5.2 AI 部队（1024 m 图共 14 支）

| 类型 | 数量 | 兵力 | 速度 | 出生点 | 首领名号 |
|---|---|---|---|---|---|
| **领主部队** | 每势力 1 支（共 3） | 140–280 | AI 速度 × 1.08（更快） | 本势力王都旁 | 「XX · XX领主」 |
| **商队** | `max(2, 总数 × 28%)`（14 支时 = 4） | 18–45 | × 0.82（更慢） | 随机城镇 / 城堡旁 | 「XX · 护卫长」 |
| **强盗团伙** | 其余（14 支时 = 7） | 22–78 | × 0.92 | 野外，距最近定居点 ≥ 60 m | 「XX（强盗头目）」；**兵力最多的那支叫「强盗首领」** |

- 每支 AI 都属于"某个势力的部队"或"无势力匪徒"，用于配色与称呼。
- 每支 AI 都有一个**首领名号**，用于战斗标题与遭遇对话框。
- 兵力最多的强盗 = **强盗首领**（这是玩家前期最有价值的"大目标"）。

### 5.3 AI 行为（只做战略层，`【骨架】` 的取舍）

| 类型 | 行为 |
|---|---|
| 领主 | 在本势力定居点之间巡逻，**按重要度加权**（城堡 1.0 / 城镇 0.8 / 村庄 0.55） |
| 商队 | 在城镇 / 城堡之间跨势力往返（道路代价低 ⇒ 自然走官道） |
| 强盗 | 野外游荡；**玩家进入视野（92 m × 随机 0.8–1.25 ≈ 74–115 m）即转为追击** |

- AI 重算路径间隔 7–13 秒；追击时 **1.4 秒**重算一次；寻路失败按 3 s → 60 s 退避。
- AI 使用 **8 m 粗栅格**（玩家 4 m）—— 为 14 支 AI 的 CPU 预算做的取舍（第 14 节）。
- **AI 之间不战斗、不占领定居点、没有外交、不会互相绕开**（明确不做）。
- 部队之间**没有物理碰撞**，只有"进入遭遇距离"才交互。

### 5.4 遭遇的接触判定

- 遭遇距离 = **7 m**，另加 **3 m 余量** ⇒ 实际 **≤ 10 m** 触发。
- 只在**时间流动时**检测（暂停时不检测）。
- 每支敌方部队有**独立冷却**（见第 8 节），冷却中不会被再次触发。

## 6. 操作与交互

### 6.1 大地图

| 操作 | 功能 |
|---|---|
| **左键点地面** | 部队寻路移动（显示目标点标记 + 贴地路径预览）；行军途中时间自动流动，抵达瞬间暂停 |
| **左键点定居点 / 部队** | **选中**并弹出详情面板（非模态，世界**不**暂停）：可「前往 / 进入 / 追踪」 |
| **再点一次同一座城** | 直接进城（等价于面板上的「进入」） |
| **点空地** | 取消选中 |
| **滚轮 / 中键右键拖拽 / WASD / F** | 缩放 / 旋转 / 平移 / 回到部队 |
| **长按空格** | 原地推进时间；行军途中按下 = 立刻停止行军并暂停 |
| **R** | 时间流速 ×1 / ×2 / ×4 |
| **G** | 进城办事（需在定居点旁，距离 ≤ 建筑半径 + 6 m） |
| **V** | 显示 / 隐藏植被 |
| **1 / 2 / 3** | 切换三个势力的领地标签显示 |
| **M** | 音效 + BGM 静音 / 恢复（左上角有提示） |
| **F5 / F9** | 快速存档 / 快速读档（有面板或战斗中不允许，并给出理由） |

**选中面板的两条路径（`【骨架】` 的交互模型）**：

- 「前往」= 只行军过去，抵达后停下；
- 「进入」= 若已在城市旁则直接进城；若离得远，则**先前往、抵达后自动进城**
  （提示条会说「先前往 XX（还有 N 米），抵达后自动进城」）；
- 部队条目只有「追踪」= 跟着它走（它改向就重新寻路；我军一停下就解除追踪）。
- **到不了的目标**（水 / 山）要给明确提示：「到不了 XX：那里无法通行」。

### 6.2 Boss 战

| 操作 | 功能 |
|---|---|
| **A / D**（或 ← →） | 左右移动（空中可微调） |
| **鼠标左键** | 攻击；连按 = 第 1→2→3 段连招；**按住 0.5 s 以上 = 蓄力**，松开射出剑气 |
| **空格** | 跳跃（短按跳得低、长按跳得高） |
| **Shift** | 闪避（前 0.25 s 无敌帧 + 残影；空中每次落地限 1 次） |
| **鼠标右键** | 弹反（0.15 s 窗口） |
| **Esc / P** | 撤退，回到大地图（**有代价**，见 11.1） |
| **F3** | 调试视图：判定盒、状态机、弹反窗口、蓄力值、特效计数 |
| **M** | 静音 / 恢复 |

### 6.3 面板的互斥与让路

- **遭遇菜单**与**进城菜单**互斥：两者都会锁时间，同一时刻只能开一个。
- 任一菜单打开时，大地图的键鼠输入**全部让路**（方向键给菜单用，相机不响应）。
- **选中面板不是模态**：它不锁时间、不拦键盘，地图照常能点（"看一眼详情"不该中断游戏）。
- 存档 / 读档在"有面板开着"或"战斗中"时被拒绝，并说明原因。

## 7. 资源与战役经济（数值核心，`【骨架】`）

### 7.1 资源一览与开局值

| 资源 | 开局 | 说明 |
|---|---|---|
| 兵力 | **37** | 队伍人数。**任何减员都不会把队伍打到 5 人以下**（保底） |
| 金币 | **400** | 唯一货币（买补给、招兵、买货、买路） |
| 补给 | **35** | 每天消耗；断粮立刻扣士气 |
| 士气 | 50（**日结后实际为 40**） | 0–100 |
| 声望 | **120** | 只增不减（当前实现）；决定领导力 |
| 兵员档次 | **0（民兵）** | 0 / 1 / 2 三档 |
| 货物 | 无 | 4 种（谷物 / 布匹 / 盐 / 铁），按货物 → 件数保存 |
| 欠薪周数 | 0 | 发薪失败 +1 |
| 天数 | 1 | 午夜 +1 |

### 7.2 全部公式（实现时逐条对齐）

设 `L = 领导力`，`N = 兵力`，`T = 档次`：

| 量 | 公式 | 开局值 |
|---|---|---|
| 领导力 | `L = clamp(floor(声望 / 100), 0, 10)` | 120 → **1** |
| 编制上限 | `capacity = 40 + 5L + floor(声望 / 20)` | 40 + 5 + 6 = **51** |
| 档次等级表 | `level_of_tier = [4, 12, 22]`（升到该档要求 `L ≥` 该值） | — |
| 档次名 | `["民兵", "正规军", "精锐"]` | 民兵 |
| 升档费 | `[—, 240, 900]` | — |
| 战斗力倍率 | `[1.0, 1.35, 1.8]` | ×1.0 |
| 战斗力 | `combat_power = N × 倍率(T)` | 37 |
| 每兵周薪 | `w(T) = max(floor((level_of_tier[T] + 3)² / 25), 1)` | 1 金（T0）/ 9（T1）/ 25（T2） |
| 周薪 | `floor(N × w(T) × (100 − 5L) / 100)` | 37 × 1 × 0.95 = **35 金 / 周** |
| 每日口粮 | `need = max(1, floor(N / 10))` | **3 件 / 天** |
| 食物加成 | `min(floor(补给 × 1.5), 15)` | 15（补给充足时封顶） |
| 欠薪惩罚 | `0`（未欠薪）否则 `clamp(欠薪周数 × 10, 1, 31)` | 0 |
| 士气 | `clamp(50 + 12L − N + 食物加成 − (断粮 ? 30 : 0) − 欠薪惩罚, 0, 100)` | **40** |
| 逃兵 | 士气 < 20 时：`max(1, floor(N × (20 − 士气) / 20 × 0.25))` | 0 |
| 战斗血量 | `260 × combat_power / 37` | 260 |
| 招募单价 | 10 金 / 人 | — |
| 补给单价基准 | 5 金 / 件（再乘繁荣度系数，见 9.4） | ≈ 5 |

> **士气为什么是 40 而不是 50**：公式里 `50` 是"中性基线"，减去 37 人的规模惩罚、
> 加上 15 的食物加成、再加 `12L`，开局正好 40 —— 意思是"你这支队伍现在有点勉强"，
> 但也远没到逃兵线（20）。这是刻意选的开局手感。

### 7.3 日结顺序（顺序不能换，`【骨架】`）

每天午夜（`time_of_day` 跨 1.0）执行一次，**按以下顺序**：

1. **吃粮**：`eaten = min(need, 补给)`，`补给 -= eaten`；
   若 `补给 == 0 && eaten < need` ⇒ 本日**断粮**。
2. **发薪**（仅当 `day % 7 == 0`）：`pay = min(周薪, 金币)`；
   发得出 ⇒ `金币 -= pay`、`欠薪周数 = 0`；发不出 ⇒ 把钱花光、`欠薪周数 += 1`。
3. **重算士气**（用上面的公式，含断粮 30 与欠薪惩罚）。
4. **逃兵结算**：按公式减员，然后**再重算一次士气**（人数少了，规模惩罚也小了）。
5. **报告**：只有发生「断粮 / 欠薪 / 逃兵」时才弹提示条（正常的日结不打扰玩家）。

> 顺序的意义：先扣粮 → 再扣钱 → 才算士气，所以"这周发不出工资"会立刻反映到当天的士气上，
> 而不是拖到下一周。

### 7.4 经济压力实测（用来校准目标项目的数值）

开局 400 金 + 35 件补给 + 37 人：

- 口粮 3 件/天、约 5 金/件 ⇒ **约 15 金/天**；周薪 35 金 ⇒ 约 5 金/天。合计 **约 20 金/天**。
- 400 金 ⇒ **约 20 天**的平衡运行；如果先花 240 金升一档（正规军），只剩 160 金 ⇒ **约 8 天**。
- 打一支 40 人的强盗：战利品 `40 × 0.85 × 6 ≈ 204 金` ⇒ **约 2 周的开销**。
- 所以"打一场养活两周"是设计基准。如果目标项目把战利品系数或兵力缩放改掉，这个比例会崩。

## 8. 遭遇（路上撞见部队）

### 8.1 触发与暂停

- 条件：时间流动中，玩家与某支 AI 的距离 `≤ 7 + 3 = 10 m`，且该 AI 不在冷却中。
- 一旦触发：
  1. **打断玩家行军**（部队停在原地）；
  2. **锁死时间**（空格无效）；
  3. 相机停止响应键鼠；
  4. 弹出遭遇对话框（中央），播放遭遇音效。
- 对话框内容：

```
遭遇 <部队名>                        ← 标题（势力色）
<类型> · <势力名>                     ← 副标题
敌方首领：<名号>                      ← 有首领时才显示
兵力：N 人     你的兵力：M 人

时间已暂停 —— 请决定行动。
```

### 8.2 四个选项（唯一决定"能不能点"的地方）

顺序固定：**动手 → 花钱 → 收钱 → 走人**。

| 选项 | 出现条件 | 代价 / 门槛 | 收益 | 之后 |
|---|---|---|---|---|
| **攻击** | 永远有 | 战后按类型损失兵力（8.4） | 战利品 + 声望 + 该部队从地图消失 | 进 Boss 战 |
| **花钱买路** | 仅 **强盗 / 商队**（领主不卖路） | `价 = max(10, floor(N × toll × (100 − d) / 100))`；钱不够则灰 | 无事通过 | 冷却 14 s + 推开 34 m |
| **索要买路钱** | 仅 **强盗 / 商队**，且 `combat_power ≥ ceil(1.5 × enemy_power)` | 无 | `金 = floor(N × toll × 1.2)`、`声望 + max(1, floor(N / 20))` | 冷却 14 s + 推开 34 m |
| **撤退** | 永远有 | 掉队 `floor(N × loss_rate)` + 士气惩罚（8.5） | 无 | 冷却 14 s + 推开 34 m |

其中：

- `toll`（每人买路钱）：**强盗 3 金 / 商队 5 金**。
- `d`（声望折扣）：`min(floor(声望 / 20), 30)` 个百分点（120 声望 → 6%）。
- `enemy_power`：`N × 倍率`，倍率 = **强盗 0.8 / 商队 1.0 / 领主 1.4**
  （所以"商队看着人少但其实难打，强盗看着人多其实虚"）。
- **领主两项都灰掉**，并给出理由（"军事贵族不吃这一套"）。

> 设计意图：`索要` 只在战力压制时亮，是"强者征税"的幻想；`买路` 是"花钱买时间"；
> 两者都必须**在按下时重新校验**（钱可能刚花掉、战力可能刚跌），校验失败就**静默保留对话框**，
> 不要弹错误弹窗。

### 8.3 推开（防止连环触发）

成交后把握手对象沿「玩家 → 它」的方向推开到 **34 m** 外（另加 4 m 余量），
否则下一帧又会立刻触发同一个对话框。

### 8.4 战果结算（`【骨架】`）

| 结果 | 兵力 | 金币 | 声望 | 位置 / 时间 | 冷却 |
|---|---|---|---|---|---|
| **胜利** | `− floor(N × loss_rate)` | `+ round(N × loot_rate × 6)` | `+ max(1, floor(N / 10))` | 原地；该部队**永久消失** | — |
| **战败** | `− max(1, floor(我方兵力 × 2/5))` | `− floor(金币 / 4)` | 0 | 传送到**最近的非村庄定居点**（优先本势力）；时间 **+12 小时** | 30 s |
| **战斗中撤退** | `− floor(N × loss_rate)` | 0 | 0 | 原地 | 25 s |
| **遭遇中撤退** | `− floor(N × loss_rate)` | 0 | 0 | 原地 + 推开 | 14 s |

各类敌人的系数：

| 类型 | 战利品率 | 我方损失率 | 战利品词 |
|---|---|---|---|
| 领主 | 0.60 | 0.12 | 辎重 |
| 强盗 | 0.85 | 0.10 | 赃物 |
| 商队 | 1.15 | 0.08 | 货物 |

> 平衡意图：**打商队是「快、弱、赚」，打领主是「久、硬、险」**。
> 商队战利品最肥但首领最弱；领主血最厚、损失率最高。

### 8.5 撤退的士气惩罚（复合乘积式，照搬原作）

```
share    = (我方阵亡 × 100 / max(1, 我方阵亡 + 敌方阵亡)) × (我方阵亡 / 我方总兵力)
penalty  = floor(share × 30 / 100)
```

注意这是**两个比值的乘积**：第一个是"这场仗里我方伤亡占比多大"，第二个是"我方损失了多大比例的队伍"。
所以"小队损失 2 人"和"大队损失 20 人"的代价可以相近 —— 这正是"小队更怕掉人"的表达。

> 由于本作的战斗是单挑表现，没有逐兵伤亡，`我方阵亡 / 敌方阵亡` 都用
> `floor(N × loss_rate)` **估算**（记为推断值），并写进结算台账。

### 8.6 参考数值（用来自检迁移是否正确）

| 敌人类别 | 兵力 | 打一场的损失 | 战利品 | 声望 | 买路价（声望 120） | 索要门槛 | 索要所得 |
|---|---|---|---|---|---|---|---|
| 强盗 | 40 | 4 人 | **204 金** | +4 | 112 金 | 战力 ≥ 48 | 144 金 |
| 商队 | 30 | 2 人 | **207 金** | +1 | 141 金 | 战力 ≥ 45 | 180 金 |
| 领主 | 200 | 24 人 | **720 金** | +20 | 灰（不卖路） | 灰 | 灰 |

## 9. 定居点（进城办事）

### 9.1 进入条件与流程

- 玩家与定居点距离 `≤ 建筑半径 + 6 m` 时可按 **G** 进城（首次靠近弹一次提示条，**不发声音**）。
- 进城时：**打断行军** → **锁死时间** → 相机停止响应 → 打开菜单。
- 出城（`离开` 或 Esc）：解锁时间、交还相机；**站在原地再按 G 可以再进**。
- 时间已被别人锁住（遭遇中 / 战斗中）时进城被拒绝（防止两个面板同时开）。

### 9.2 菜单结构（数据驱动，`【骨架】`）

菜单条目顺序固定，末尾附一个「数量」条目：

| 定居点类型 | 服务条目 |
|---|---|
| 城堡 | 买补给 / 驻军存入 / 驻军取出 / **离开** |
| 城镇 | 买补给 / 招募 / 切换货物 / 买入货物 / 卖出货物 / 驻军存入 / 驻军取出 / **离开** |
| 村庄 | 买补给 / 招募 / 驻军存入 / 驻军取出 / **离开** |

- 每条都有「文本 / 是否可点 / 提示」三件套；**灰掉的条目必须给出理由**
  （"钱不够（还差 N 金）"、"编制已满（51/51）"、"志愿者不足"、"驻军为空"…）。
- **数量**：`1 → 5 → 10 → 1` 循环，影响买补给 / 招募 / 买卖货物 / 驻军。
- 菜单顶部固定显示状态行：`名字 / 类型 / 繁荣度（档名）/ 驻军 / 志愿者`。

### 9.3 各服务的行为

| 服务 | 规则 |
|---|---|
| **买补给** | 单价 = 按繁荣度浮动的补给价；钱不够时**自动少买几件**（返回实际件数），不报错 |
| **招募** | 实际招募 = `min(数量, 志愿者池, 编制余位, floor(金币 / 10))`；**志愿者池按实际招到的人数扣减** |
| **买卖货物** | 先「切换货物」选中 4 种之一，再买 / 卖当前数量；买入受钱限制、卖出受持有量限制 |
| **驻军存入** | 把兵留在城里（**工资按人数算，养不起就先存起来**）；**队伍里至少留 5 人** |
| **驻军取出** | **免费**（自家的兵），但受**编制余位**限制 |

> 驻军当前**不参与战斗**（第 14 节），它的意义纯粹是"降低周薪负担的蓄水池"。

### 9.4 物价公式（`【骨架】`）

```
繁荣系数 = 100 + (50 − 繁荣度) × 60 / 100      # 繁荣 0 → 130；繁荣 100 → 70
买价 = max(1, floor(基准价 × 繁荣系数 × (100 + 本地价差) / 10000))
卖价 = max(1, floor(买价 × 60 / 100))
```

- 四种货物的基准价：**谷物 8 / 布匹 15 / 盐 24 / 铁 38**。
- **本地价差**：每座定居点对每种货有一个 ±15% 的固定偏差（同一种子永远一样），
  让"这儿的盐便宜"成为可记忆的地理知识。
- **繁荣度**：`clamp(floor(重要度 × 70) + 随机(−25, +25), 0, 100)`，开局时确定；
  档名：0–20 荒废 / 20–40 萧条 / 40–60 平常 / 60–80 富庶 / 80–100 繁荣。

**示例（谷物，基准 8，价差 0）**：

| 繁荣度 | 买价 | 卖价 |
|---|---|---|
| 80（富庶） | 6 | 3 |
| 50（平常） | 8 | 4 |
| 20（萧条） | 9 | 5 |

> ⚠ **诚实提示**：因为卖价统一打 6 折，**纯跑商在当前数值下几乎不赚钱**
> （最理想价差约 +1 金/件）。贸易在当前版本的真实作用是「把战利品变现 / 把钱换成货物暂存」，
> 不是主要收入来源。如果目标项目希望"跑商"成为可行流派，需要调卖价百分比（如 75–85%）
> 或加大本地价差范围 —— 这是**明确的可选改动**，但不改就要在文档里同步说明。

### 9.5 志愿者回流

- 上限：城镇 20 / 村庄 12 / 城堡 0；**开局即满**。
- 每 **2 天**，每座定居点志愿者 **+1**，不超过上限。
- 意义：玩家不能在一个村子反复刷兵，必须跑多个村子（或等）。

## 10. Boss 战（2D 横版动作，`【骨架】` 的结构 + `【可调】` 的手感）

### 10.1 场景与镜头

| 项 | 值 |
|---|---|
| 竞技场宽度 | **1500 px**（≈ 2.25 个屏幕），两侧岩壁不可越过 |
| 地面 | 平地 + **2 个可跳上去的低平台**（各距两侧边缘 230 px、高 64 px、宽 150 px） |
| 镜头 | 水平跟随双方中点；双方距离 < 420 px 时 2.6 倍（近），≥ 420 px 时 1.95 倍（远），平滑插值 |
| 背景 | 4 层视差（远山 / 中景树林或废墟或仙人掌 / 近景灌木岩石 / 前景草丛），**由遭遇点地形决定配色**：雪山 / 沙漠 / 草原三套 |
| 玩家形象 | 64 px 高骑士（头 / 躯干 / 双臂 / 双腿 / 剑 / 披风） |
| Boss 形象 | 164–192 px 重甲巨人（领主 192 持巨斧 / 强盗 176 持巨斧 / 商队 164 持长剑），体型与配色按类型区分 |

### 10.2 双方数值映射（大地图 → 战斗，`【骨架】`）

| 项 | 公式 / 值 |
|---|---|
| 玩家血量 | `260 × combat_power / 37`（开局 37 人 ×1.0 ⇒ 正好 260） |
| 玩家气力 | 100，回复 24/s（停止消耗 0.65 s 后开始） |
| Boss 血量 | 领主 `300 + N × 1.10` / 强盗 `130 + N × 2.10` / 商队 `110 + N × 1.70` |
| Boss 破防值 | 领主 `90 + N × 0.22` / 强盗 `55 + N × 0.42` / 商队 `48 + N × 0.38` |
| Boss 伤害系数 | 领主 ×1.00 / 强盗 ×0.92 / 商队 ×0.82 |
| Boss 体型 | 70 × 180 px（碰撞盒） |
| Boss 移动速度 | 92 px/s |

  - 领主：6 招全有（含二阶段裂隙）；

**选招规则**（每次出招后按此判定）：

1. 过滤掉「二阶段专属但还没进二阶段」的招；
2. 过滤掉「距离不在 `[最近距离, 最远距离]` 内」的招；
3. 过滤掉「上一招已经连续用了 2 次」的招；
4. 在剩下的招里**按权重随机**（随机数必须走**本场战斗已播种的随机流**，否则不可复现）；
5. 若没有可用招式 ⇒ 走向玩家，走到 170 px 内或 1.6 s 后强制再选一次。

### 10.5 伤害结算顺序（`【骨架】`，顺序错了会出各种"无敌 bug"）

每次命中按下面顺序判定，**先满足者终止**：

1. **玩家在闪避无敌帧内** ⇒ 不受伤（若在完美闪避窗口内 ⇒ 触发慢动作 + 特效，然后返回）；
2. **玩家在弹反窗口内 && 招式可弹反** ⇒ 弹反成功：Boss 破防 +34、硬直 0.85 s、玩家获得 1.3 s 反击窗口、
   顿帧 + 火花 + 白闪 + 专属音效，返回；
   - **投射物被弹反 ⇒ 反弹回去打 Boss**（飞斧会飞回去砸自己）；
3. **玩家处于受击无敌 / 其它无敌** ⇒ 不受伤；
4. 计算伤害：
   - 玩家打 Boss 且**反击窗口有效** ⇒ **×2.0**；
   - 招式自带会心（第 3 段）⇒ 再 ×1.3；
   - Boss 处于**破防状态** ⇒ 玩家伤害**再 ×1.5**；
   - Boss 打玩家 ⇒ 乘**类型系数**；
5. 击退：Boss 受到的击退 **×0.22**；
6. 施加伤害 + 进入受击硬直 + 无敌帧；
7. 表现：顿帧（轻 0.05 / 重 0.10）、火花、刀光、震屏（轻 3 / 中 7 / 重 13，持续 0.14 / 0.24 / 0.42）、伤害数字飘字；
8. 玩家命中 Boss ⇒ **累加破防值**。

> 同一次攻击对同一目标**只结算一次**（用"本次攻击已命中集合"去重），否则多帧判定会瞬间打十几下。

### 10.6 破防 / 霸体 / 二阶段

**破防**

- Boss 有一个"破防值上限"（10.2 的公式），玩家每次命中累加，**弹反一次 +34**。
- 破防值在 **1.5 s 未受击后**开始以 **7 / s** 衰减。
- 累加到上限 ⇒ 进入 **破防 3.0 s**：Boss 跪地不动、受伤 **×1.5**，结束后清零。
- **霸体**：普通命中**不打断** Boss 出招（只有闪白反馈）；只有**弹反**和**破防**能打断它。

**二阶段**

- Boss 血量 < **50%** 时触发怒吼转场：**1.7 s 无敌** + 全屏震屏 + 配色转红 + 眼睛变亮。
- 转场后：攻速 **×1.20**（后摇与间隔都缩短）、出招间隔从 **0.55 s → 0.34 s**、
  解锁**崩界裂隙**（仅领主有这招，因为只有领主的招式表里有它）。

## 11. 结果结算与成长闭环

### 11.1 Boss 战的三种结束

| 结果 | 触发 | 演出 | 之后 |
|---|---|---|---|
| **胜利** | Boss 血量归零 | 「胜利」大字 + 胜利音效，3.2 s | 结算战利品 / 损失 / 声望（8.4）；该部队从地图消失 |
| **战败** | 玩家血量归零 | 「战败」大字 + 失败音效，3.2 s | 掉 40% 兵力、掉 25% 金币、被送回最近城镇、时间 +12 小时 |
| **撤退** | Esc / P | 「撤退」大字，2.2 s | 掉队 + 士气惩罚（8.5） |

- 结束流程：显示结果 **2.6 s** → 黑幕淡入 0.6 s → 销毁战斗场景 → 恢复大地图（战斗 BGM 长淡出、地图 BGM 淡入）
  → 交还相机与输入 → **解锁时间**（战败时玩家若在行军中则时间继续流；其余情况原地暂停）。
- ⚠ **文档校对点**：README 的操作表里写"Esc 撤退（无惩罚）"，但**实现是有代价的**（掉队 + 士气）。
  迁移时以实现为准。

### 11.3 成长的四条杠杆（`【骨架】`）

1. **钱 → 兵**：招募 10 金 / 人，受「志愿者池 + 编制 + 钱」三重限制。
2. **兵 → 血量**：战斗力 `N × 档次倍率` 直接换 Boss 战血量。**这是唯一的"变强"途径**。
3. **声望 → 领导力**（`floor(声望/100)`，上限 10）：同时影响
   **编制（+5 / 级）**、**军费折扣（−5% / 级）**、**买路折扣（每 20 声望 −1%，上限 −30%）**。
4. **档次 → 倍率**（1.0 / 1.35 / 1.8）：升档要领导力达标 + 付钱，**每兵周薪也从 1 → 9 → 25 暴涨**。
   所以升档是"战力换经济压力"的抉择。

> **没有胜利条件**：当前是一个沙盒，没有"统一全图"或"通关"判定。
> 目标感来自「钱不够了 → 去打一场 → 更强了 → 打更硬的」。

### 13.2 文案规范（`【骨架】` 的体验约定）

1. **全部中文**，语气是"战队文书"，不卖萌、不用感叹号堆情绪。
2. **数字必须带单位**（"35 金"、"3 件"、"4 人"、"−2 士气"）。
3. **灰掉的条目必须给理由**，并且理由要具体：
   - 「钱不够（还差 12 金）」而不是「无法购买」；
   - 「编制已满（51/51）」而不是「不可招募」；
   - 「军事贵族不吃这一套」而不是「不可用」。
4. **失败要有反馈**：进城失败 / 目标不可达 / 存读档被拒，都要有明确的提示条。
5. **避免无声的静默失败**（旧实现踩过：撤退后时间永久冻死，玩家看不出发生了什么）。

| 出招前摇 | **可弹反 = 清脆金属上扬**；**不可弹反 = 低沉闷响**（不看画面也能听出该弹还是该闪） |
| 命中 | 玩家打中 = 剑刃；会心 / 反击换更亮金属音；Boss 打中玩家 = 沉闷重击 |
| 弹反成功 | 打铁声（弹返投射物升调 + 回旋风） |
| 完美闪避 | 反向上扫的"吸入感" + 上行铃声 |
| 蓄力完成 | 聚气完成提示音 |
| 胜负 | 胜利 / 失败 / 返回告示音 |
| 大地图 | 行军马蹄声；**点地图下达移动命令时不播音效** |

> 最后一条看起来奇怪但很重要：移动命令是高频操作，每次点地都响一声会吵死人。
> 同样地，**进城提示条、日结提示条都不播音效**（提示条是纯视觉的）。

## 14. 已知简化（移植时**不要**顺手"补全"的地方）

这些是当前版本**刻意不做**的，写在这里是为了防止接手 AI 自作聪明地加需求、把项目做成另一个游戏。
（原文完整清单见 [README.md](../README.md) 第五节。）

1. **战斗是"玩家单挑 1 个敌方首领"，不是部队会战**：场上没有小兵、没有阵型、没有兵种、
   没有战术层士气。兵力只是一个数字，只影响 Boss 血量 / 破防值、玩家血量、战损。
2. **AI 只做战略层行为**：不会互相开战、不会占领定居点、没有外交与关系、不会互相绕开。
3. **AI 寻路 8 m 粗栅格，玩家 4 m 细栅格**（CPU 预算取舍），所以 AI 路径偶尔"贴边"。
4. **战争迷雾探索后永久可见**，没有动态可见性；只压暗地表，不影响海天。
5. **没有物理碰撞体**：部队靠采样高度场贴地，没有刚体 / 车辆 / 子弹物理。
6. **没有粒子与后处理堆料**（只有发光 + 色调映射 + 调色）。
7. **小地图不可点击、不可旋转**。
8. **只有一个存档槽**，无自动存档、无读档二次确认。
9. **没有主菜单与设置界面**（启动直接进游戏）。
10. **玩家没有等级 / 装备 / 技能树**：唯一的成长是"钱 → 兵 → 档次"。
11. **剑气只能朝正面**，没有空中上下方向剑气。
12. **三种首领共用同一套 AI 状态机与招式骨架**，差异在体型 / 配色 / 武器 / 招式表 / 数值，
    不是三套独立的 Boss 行为。
13. **驻军不参战**，只是"降低周薪的蓄水池"。
14. **贸易利润很薄**（卖价 6 折），本质上不是主要收入来源（见 9.4）。
15. **没有胜利条件**（沙盒）。
16. 首帧生成约 3 秒（含地图与音效合成），期间只有加载遮罩。

## 15. 迁移验收清单

按这个清单逐条跑，全过即视为"玩法迁移完成"。

### A. 世界与时间

- [ ] 用固定种子生成地图：3 势力、18 定居点（每势力 1 城堡 + 2 城镇 + 3 村庄）、道路连成网、河上有桥。
- [ ] 默认暂停；点地面 → 部队出发 + 时间开始流动；抵达瞬间自动暂停。
- [ ] 行军途中按空格 → 立即停下并暂停；再按住空格 → 时间流动；松开 → 立刻暂停。
- [ ] `R` 在 ×1 / ×2 / ×4 之间切换，流速影响日结频率。
- [ ] 1 天 = 120 秒（×1），起始 08:00，午夜天数 +1 并触发日结。
- [ ] 暂停时 AI 不动、日结不触发、遭遇不检测。

### B. 遭遇

- [ ] 靠近 AI 部队 ≤ 10 m 时弹对话框、时间锁死、行军被打断。
- [ ] 四个选项按条件出现：攻击（永远）/ 买路（仅强盗商队）/ 索要（战力 ≥1.5× 且仅强盗商队）/ 撤退（永远）。
- [ ] 领主的两项灰掉且给出理由。
- [ ] 买路价 = `max(10, N×toll×(100−d)/100)`；声望 120 时折扣 6%。
- [ ] 索要成功后得 `floor(N×toll×1.2)` 金、声望 `+max(1, floor(N/20))`。
- [ ] 撤退 / 买路 / 索要后：冷却 14 s，且被推开 34 m。
- [ ] 战败被送回最近的非村庄定居点，时间 +12 h，掉 40% 兵、25% 钱。

### C. 经济

- [ ] 开局：37 兵 / 400 金 / 35 补给 / 声望 120 / 档次 0；日结后士气 = 40。
- [ ] 领导力 = 1，编制 = 51，周薪 = 35 金。
- [ ] 每天消耗 3 件补给；第 7 天发薪；发不出时欠薪周数 +1 且士气额外下降。
- [ ] 补给耗尽 → 断粮扣 30 士气；士气 < 20 → 开始逃兵，且队伍不会低于 5 人。
- [ ] 升档：领导力 ≥ 4 才能升正规军（240 金），倍率 1.0 → 1.35；再升精锐要领导力 ≥ 12、900 金。
- [ ] 招募受「志愿者 + 编制 + 钱」三重限制；志愿者每 2 天 +1。

### D. 定居点

- [ ] 靠近按 G 进城：时间锁死、行军打断；Esc 出城恢复。
- [ ] 城堡只有「补给 / 驻军」；城镇有「补给 / 招募 / 贸易 / 驻军」；村庄有「补给 / 招募 / 驻军」。
- [ ] 数量在 1 / 5 / 10 之间循环，影响所有交易。
- [ ] 谷物在繁荣 80 的城买价 6、繁荣 50 买价 8、繁荣 20 买价 9；卖价一律 6 折。
- [ ] 驻军存入后队伍 ≥ 5 人；取出免费但受编制上限限制。

### E. Boss 战

- [ ] 40 人强盗的 Boss 血量 214、破防 72；200 人领主血量 520、破防 134。
- [ ] 玩家血量 = `260 × 战斗力 / 37`（37 人 1 档 = 260；51 人 2 档 ≈ 484）。
- [ ] 三段连招：只有后摇前 70% 能接下一段；第 3 段必定会心 ×1.3；跳跃不能取消普攻。
- [ ] 闪避前 0.25 s 无敌；判定帧内闪避触发 0.6 s 慢动作。
- [ ] 弹反窗口 0.15 s：成功则 Boss 破防 +34、硬直 0.85 s、1.3 s 内下一刀 ×2；失败有 0.4 s 后摇。
- [ ] 红色预警的重招**弹不动**（会正常受伤）；白色招式可弹。
- [ ] 飞斧被弹反后会反弹打 Boss 自己。
- [ ] 破防值 1.5 s 未受击后以 7/s 衰减；打满 → Boss 破防 3 s、受伤 ×1.5。
- [ ] Boss 血量 < 50% 进入二阶段：1.7 s 无敌怒吼、攻速 ×1.2、出招间隔 0.55 → 0.34。
- [ ] 三种敌人的招式表正确（领主 6 / 强盗 4 / 商队 3），伤害系数 1.0 / 0.92 / 0.82。
- [ ] 同一招不会连续使用超过 2 次；Boss 不会因为距离死区而站着不动。
- [ ] 战斗结束后 2.6 s + 0.6 s 淡出回到大地图，时间解锁、相机与输入交还。

### F. 存档与 UI

- [ ] F5/F9 只在无面板、非战斗时可用，否则给出理由。
- [ ] 读档后地图按种子重新生成，已消灭的部队不复活，不重跑日结。
- [ ] 所有灰掉的条目都有具体的理由文案。
- [ ] 操作说明里的按键名是运行时读取的（改键位后自动变）。
- [ ] 所有飘字 / 特效到期自动消失，打完后屏幕干净。

## 16. 建议的实现顺序（给接手 AI 的里程碑）

| 里程碑 | 内容 | 完成标志 |
|---|---|---|
| **M1 时间与移动** | 一张平面地图 + 玩家部队 + 点地寻路 + 四状态时间机 + 流速 + 昼夜 | 能"点地走、按空格推进、抵达自动暂停" |
| **M2 经济骨架** | 五资源 + 日结 + 周薪 + 士气 + 逃兵 + 编制 | 什么都不做，20 天后队伍会崩 |
| **M3 定居点** | 三类服务菜单 + 补给 / 招募 / 贸易 / 驻军 + 物价公式 | 能在城里把钱花完、把兵招满、把兵存起来 |
| **M4 遭遇与 AI** | 三类 AI + 视野 / 巡逻 / 追击 + 遭遇菜单四选项 + 推开 + 冷却 | 路上会被追、被拦、能买路或索要 |
| **M5 战斗** | 竞技场 + 玩家 4 招 + 闪避 / 弹反 / 蓄力 + Boss 6 招 + 破防 + 二阶段 + 结算 | 能打赢 40 人强盗，打不过 200 人领主 |
| **M6 打磨** | 顿帧 / 震屏 / 飘字 / 音效 / HUD / 存档 / 文案 | 第 15 节清单全绿 |

> 顺序不要换：M1 的手感决定整局节奏，M2 的数字决定难度曲线，M5 的战斗是"验证前面所有数值"的地方。
> 如果先做战斗，会得到一套"打起来爽但经济对不上"的孤岛。
