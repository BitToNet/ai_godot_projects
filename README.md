# 骑马与砍杀风格 · 3D 战略大地图 +《神之天平》风格 Boss 战斗（Godot 4.3+ / GDScript）

一个完全**程序化生成**的《骑马与砍杀》风格战略大地图 Demo。
**不使用任何外部模型 / 贴图 / 音频**：所有地形、水面、植被、城堡、城镇、村庄、
马匹与骑手，全部由 `ArrayMesh` + `SurfaceTool 风格的手写几何` + `ShaderMaterial` 在运行时生成。

- 引擎：**Godot 4.3+**（实测运行于 Godot **4.7.stable**，Forward+ / Metal）
- 语言：GDScript（77 个脚本，约 12900 行）+ 4 个手写 Shader（约 370 行）
- 地图：1024 × 1024 世界单位，最大高度 ≈ 170 m，海平面 = 0
- 随机性：**单一 `map_seed` 控制全局**，换一个种子就能得到一张完全不同的、但同样合理的地图

## 一、运行方法

### 1. 直接运行（推荐）
```bash
# 用 Godot 4.3+ 打开工程目录（项目文件夹里已有 project.godot）
godot --path /path/to/godot_opus5.5
# 或者打开 Godot 编辑器 → 导入 → 选择 project.godot → F5
```
主场景是 `res://scenes/Main.tscn`，启动后会显示 Loading 遮罩，
约 **3 秒**（Apple M4 实测 3.0 s）完成全部程序化生成，再加上约 **1.6~2 秒**合成 28 种音效
（Loading 遮罩里会显示「合成音效（程序化 PCM）…」，不会卡界面），随后自动进入游戏并响起
大地图背景音乐「旧时日」（作者提供的母带，见第四节）。
不想听音效可以在 `scripts/core/AudioConfig.gd` 里把 `enabled` 设为 `false`（跳过合成），
游戏内按 **M** 也可以随时把音效 + 背景音乐一起静音 / 恢复。

### 2. 验证过的命令行方式
```bash
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/qiulong/deepseek/godot_opus5.5
```
本工程在 **macOS 15.5 / arm64 / Godot 4.7.stable** 上完整跑通：
无脚本报错、无 Shader 编译错误、无运行时 ERROR。

### 3. 第一次运行说明
- `.godot/`（Godot 的本地缓存，含 `global_script_class_cache.cfg`）**不在仓库里**：
  它已被 `.gitignore` 忽略，因为其中大部分是与本机显卡驱动绑定的 shader 二进制缓存。
  所以**克隆后第一次运行之前，必须先做一次缓存扫描**，二选一：
  ```bash
  # 方案 A：用编辑器打开一次（F5 运行），Godot 会自动重建缓存
  godot --editor --path /path/to/godot_opus5.5
  # 方案 B：命令行做一次「打开编辑器并立刻退出」的无头扫描
  godot --headless --editor --quit --path /path/to/godot_opus5.5
  ```
  之后再 `godot --path ...` 就正常了。
- 如果跳过这一步直接运行，会报 `Parse Error: Could not find type "MapConfig"` 之类的错
  ——这是 Godot 还没建立全局 `class_name` 索引导致的，**不是代码问题**，按上面做一次即可。
- 如果导入时提示图标导入，允许即可（`icon.svg` 是程序生成的占位图标）。

### 4. 音效与背景音乐自检（可选，命令行）
```bash
# 逐个音色的体检报告（时长 / 峰值 / RMS / 三频段能量 / 过零率 / 衰减）
godot --headless --path /path/to/godot_opus5.5 --script res://tools/sfx_tool.gd
# 音色指纹：28 个音色的 PCM 逐字节比对 tools/sfx_pcm.json（合成优化后必须一模一样）
godot --headless --path /path/to/godot_opus5.5 --script res://tools/sfx_tool.gd -- --check
# 再导出全部音色为 audio_preview/*.wav 试听
godot --headless --path /path/to/godot_opus5.5 --script res://tools/sfx_tool.gd -- --wav
# 战斗音效联调：脚本化打一场 Boss 战，统计每个音效触发次数
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/sfx_battle_check.gd
# 大地图音效联调：行军 + 遭遇
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/sfx_map_check.gd
# 背景音乐联调：两首曲目加载 / 循环 / 开战切换 / 回到大地图 / 静音
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/bgm_check.gd
# 音色 PCM 缓存自检：冷启动落盘 / 热启动逐字节一致 / 坏缓存自愈 / setup 命中
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/audio_cache_check.gd
```
音效两个脚本退出码 `0` = 关键音效全部触发过，`1` = 有缺失并打印缺失清单；
`bgm_check.gd` 退出码 `0` = 两首曲目都正常起播、切换与静音，`1` = 音频缺失或状态不对。
`audio_cache_check.gd` 退出码 `0` = 缓存可命中且 PCM 与冷启动逐字节一致，`1` = 键 / 校验 / 自愈有问题。
音色 PCM 缓存放在 `user://sfx_cache/`（约 679 KB），**删掉即重新合成**：首次启动多花约 1.1~1.3 秒，
之后启动只花几毫秒（`Sfx.setup()` 实测 1.35 秒 → 9 毫秒）。

### 5. 规模热点探针（可选，命令行）
```bash
# 三条主线（植被筛选 / 地形建块 / A* 寻路）的实测表 + 与基线比对，退出码 0 = 与基线一致
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/scale_probe.gd
# 有意改了规模或优化了热点之后更新基线（结构量会跟着变，属于「显式接受」）
godot --headless --path /path/to/godot_opus5.5 --fixed-fps 60 --script res://tools/scale_probe.gd -- --write-baseline
```
结构量（实例数 / 区块数 / 变换指纹 / 地形位置与索引指纹 / 每对路径的点数与展开节点数）必须与
`tools/scale_baseline.json` **精确一致**；耗时只做上界比对（× 1.6 记 WARN，× 2.5 判失败）——
这样它既能当「优化有没有真的变快」的量尺，也能当「重构有没有偷偷改变世界」的看守。
注意 headless 下没有渲染：draw call / 视锥剔除 / MultiMesh 上传的收益它测不到。

### 6. 换一张地图
打开 `scripts/core/MapConfig.gd`，修改：
```gdscript
@export var map_seed: int = 20250929   # 换成任意整数
```
或在编辑器里选中 `Main` 节点 → Inspector → `config` 新建一个 `MapConfig` 资源后修改。
所有参数（噪声强度、河流数量、植被密度、定居点数量、相机范围、昼夜时长……）
都是 `@export`，可以在 Inspector 里实时调。

## 二、操作说明

| 操作 | 功能 |
|---|---|
| **鼠标左键点击地面** | 部队 A* 寻路移动（显示目标点标记 + 贴地路径预览线）。**行军途中世界时间自动流动，抵达目的地的瞬间世界时间立刻暂停** |
| **鼠标滚轮** | 缩放，相机高度 20 → 400（越近俯角越小，越接近平视；越远越接近俯视） |
| **中键 / 右键拖拽** | 旋转视角（改变 yaw） |
| **W A S D / 鼠标推到屏幕边缘** | 平移视野 |
| **F** | 视角拉回部队 |
| **长按空格（部队已停下）** | 世界时间才开始流动，松开立刻恢复暂停（原地「等待 / 推进时间」） |
| **行军途中按空格** | 行军立刻中断，部队就地停下并进入暂停状态 |
| **R** | 切换时间流速 ×1 / ×2 / ×4 |
| **V** | 显示 / 隐藏植被 |
| **1 / 2 / 3** | 切换某势力定居点标签的显示 |
| **M** | 音效 + 背景音乐静音 / 恢复（切换时左上角有提示） |
| 悬停定居点 / 部队 | 显示名称、类型、势力、驻军/兵力提示 |
| 走到 AI 部队身边 | 弹出「遭遇 XX：攻击 / 撤退」对话框 |
| 遭遇任意 AI 部队时点「攻击」 | 进入 2D 横版 **Boss 战斗场景**（领主 / 商队 / 强盗都会打，见下一节） |

拉到最远（高度 ≥ 275）自动进入**战略视图**：植被整块剔除，定居点/部队标签自动放大。

### Boss 战斗场景操作（2D 横版）

| 操作 | 功能 |
|---|---|
| **A / D**（或 ← →） | 左右移动 |
| **鼠标左键** | 攻击（连按 = 第 1→2→3 段连招；**按住 0.5s 以上 = 蓄力**，松开射出剑气） |
| **空格** | 跳跃（**短按跳得低、长按跳得高**） |
| **Shift** | 闪避（前 0.25s 无敌帧 + 残影；空中每次落地限 1 次） |
| **鼠标右键** | 弹反（0.15s 窗口，成功则 Boss 破防 + 硬直 + 下一刀「反击斩」×2） |
| **F3** | 调试视图：显示 Hitbox / Hurtbox、状态机状态、弹反窗口与蓄力计时、音效累计次数与当前 BGM |
| **M** | 音效 + 背景音乐静音 / 恢复 |
| **Esc / P** | 撤退，返回大地图（无惩罚） |

Boss 战每次出招前都有**声音预警**：可弹反的招式是清脆的金属上扬音，无法弹反的重招是低沉的闷响，
不看画面也能听出该弹反还是该闪避。

## 五、已知简化 / 未实现的部分（诚实说明）

1. **战斗形式是"单人 vs 1 个敌方头目"的决斗，不是部队会战**。现在大地图上任何部队点「攻击」
   都会进入 2D 横版战斗场景，但场上只有玩家自己一个人对阵对方头目；
   兵力数字只影响 Boss 的 HP / 破防值与我方战损，没有士兵单位参战，也没有阵型 / 兵种 / 士气。
2. **音效是程序化合成的，背景音乐是两首外部母带（本项目唯一的外部音频资源）**。音效按规范
   要求不使用外部音频素材，28 种全部由 `scripts/audio/SfxSynth.gd` 在启动时用代码合成 PCM
   （正弦表 + 噪声 + 金属泛音 + 双二阶滤波），没有任何**音效** `.wav` / `.ogg`。两首 BGM 则是
   **外部音频资源**：`audio/bgm/*.ogg`，由作者提供母带后转码接入（见「背景音乐」一节），
   **授权信息以作者为准，本工程不做声明** —— 这是应需求方要求对"不使用任何外部音频"这条原始
   约定做的**有意偏离**，且只发生在 BGM 上。（更早的版本曾用 XSXB-Band 工作室渲染两首 CC0 民乐
   「山河行旅」/「金戈铁马」，已被本轮替换；旧成品留在 git 历史与 `F:\aigc_code\XSXB-Band\exports\` 里。）音效的代价是：① 首次启动要合成约 1.1~1.3 秒（之后走 PCM 缓存只要几毫秒，见 `SfxCache.gd`；Loading 里显示进度，
   可把 `AudioConfig.enabled` 关掉跳过）；② 音色是"合成器风格"的，不如真实录音的层次与细节；
   ③ 单一混响/空间感，没有做 HRTF、遮挡、混响区。音效清单：挥砍命中（轻/重/暴击）、
   弹反打铁、闪避破风、完美闪避、脚步、跳跃落地、马蹄、受击闷哼、破防、二阶段怒吼、
   蓄力完成、剑气、Boss 前摇预警（可弹反 / 危险）、遭遇 / 行军号角 / 开战 / 胜 / 败 / 返回。
3. **AI 只做战略层行为**。领主/商队/强盗在同一张地图上按栅格 A* 移动，不会互相战斗、
   不会占领定居点、没有外交与阵营关系，也不会绕开彼此。
4. **AI 寻路用 8m 粗栅格**（玩家用 4m 细栅格）。因此 AI 的路径偶尔会比玩家"贴边"一些，
   这是为了 14 支 AI 每 1.4~4 秒重算一次的 CPU 预算做的取舍。
5. **河流是"下切出的河道 + 三角带水面"**，不是真正的水流模拟；水位是静态剖面（无涨落、
   无水流动画，只有波形滚动方向暗示流向）。湖泊水面是矩形平面（不是按湖岸形状裁剪的网格），
   湖特别不规则时水面边缘可能与湖岸有细微出入；我用"水位略低于岸边 + 泡沫"来掩盖。
6. **战争迷雾是"探索后永久可见"**，没有做"敌方视野遮挡 / 回头再探索"的动态可见性；
   迷雾只影响地形、建筑、植被的表面颜色，海面与天空不受影响。
7. **树不投影**（`cast_shadow = OFF`）：为了 5000+ 实例的性能取舍，只有建筑与部队投影。
8. **距离雾不是体积雾**（未开启 `volumetric_fog`），是深度雾 + 天空渐变近似大气散射。
9. **地形物理碰撞体没有生成**：部队靠解析采样高度场贴地（性能更好），
   所以没有刚体/车辆/子弹物理；`Area3D`/`CollisionShape3D` 全部未使用。
10. **粒子与后处理较少**：没有粒子特效（火焰、烟尘、雨雪），后处理只有 Glow + 色调映射 + 调整。
11. **LOD 之间只有裙边遮挡，没有做几何渐变（geomorphing）**，快速旋转相机时极远处
    偶尔能察觉到 LOD 切换的分辨率变化。
12. **小地图不支持点击跳转**，也不能旋转；它是一张烘焙纹理 + `_draw()` 叠加。
13. **UI 未做分辨率自适应细节打磨**：按 1600×900 基准布局（`canvas_items` 拉伸），
    极端宽高比下小地图与面板的位置可能需要微调。
14. **地形着色器中的 splat 图分辨率 512²**（2m/texel），贴到 1024 单位的地图上，
    近距离（相机高度 < 20m）贴图边界会略显模糊——这是为了节省显存与生成时间的取舍。
15. **没有存档 / 读档**，每次启动都是按种子即时生成；没有主菜单与设置界面。
16. **Boss 战的已知简化**：
    - 场上只有一个敌方头目、一块平地竞技场，没有小怪、没有多阶段地形；
    - 三种头目共用同一个 AI 状态机与姿势库（差异在体型 / 配色 / 武器 / 招式表 / 数值），
      不是三套独立的 Boss 行为脚本；
    - Boss 的 6 个招式共用同一套"前摇→判定→后摇"骨架，没有做骨骼动画资源级的分支混合；
    - 打击音效是程序化合成的（命中 / 弹反打铁 / 闪避 / 完美闪避 / 脚步 / 破防 / 怒吼 / 预警），
      与顿帧/震屏/火花/数字叠加做"打击感"，但仍是合成器音色而非录制素材；战斗 BGM 例外，
      是外部母带（见上面「背景音乐」一节）；
    - 玩家没有等级、装备、技能树，Boss 战的结果不影响大地图数值（除兵力增减与部队消失）；
    - 角色绘制是"多边形+骨骼"的低多边形风格，不是像素美术，和《神之天平》的像素画风有差距；
    - 剑气只能向正面发射，没有上下方向的空中剑气；
    - 战斗背景的视差层是"程序化山形/树形重复"，不是逐关卡手工设计的美术资源。
17. 首帧生成约 **3 秒**（513² 高度场 + 3 套导航栅格 + 18 座定居点 + 21 条道路 + 5000+ 植被），
    期间显示 Loading 遮罩；如果要 < 1 秒启动，需要把部分环节移到线程或降低 `heightmap_res`
    （音效合成再叠加约 1.6 秒，同样在 Loading 遮罩内完成；两首 BGM 是现成的 Ogg，
    只在首次播放时解码，几乎不占启动时间）。
